# 한국어 전체 번역 → 코드 추출: 20문장 실험

2026-11-03. 기존 직접 JSON 추출을 대체할 후보로, Qwen3-0.6B에 번역만 한 번 요청하고 영어에서 코드로 조건을 추출했다. 번역문 전체를 기존 MiniLM의 자유 문장 입력으로 사용했다. 모델·규칙·매칭 설정은 실행 도중 수정하지 않았다.

## 데이터와 실행

- 한국어 20문장: 같은 뜻의 표현 변형, 구어체, 부정, 미언급, 불확실성, 정답 없는 질문.
- 기존 감사 보고서의 성공 특징 그룹 10개(17개 후보)와 vpu 사진 그룹 1개(5개 후보): 총 11그룹·22개 후보 기록.
- 각 문장을 각 그룹의 후보 전체와 비교: 20×11=220회. 모델 호출은 총 번역 20회이며 그룹별 재번역은 하지 않았다.
- 모델 인스턴스 하나를 유지, CPU float32, 2 threads, 오프라인 캐시 사용.
- 주 평가 그룹·대상은 실행 전에 문장별로 지정했다. 다른 그룹 결과는 탐색용이며 정답률을 계산하지 않았다.
- 초기 Qwen 저장값을 참고한 약한 정답과 실제 사진 기반 사례가 섞여 있고, 물품·사진 중복이 있다. 실제 사용자 일반 정확도로 해석하지 않는다.

## 결과

| 항목 | 결과 |
|---|---:|
| 번역·추출 실행 완료 | 20/20 |
| 품목·색·스티커 상태 전체 일치 | 10/20 |
| 번역·코드 추출 시간 중앙값 | 약 2.52초 |
| 제한 적용 전 주 그룹 정책 판정 | matched 8 / no_match 6 / needs_confirmation 6 |
| 검토 제한을 적용한 실제 최종 판정 | 전부 needs_confirmation |

중앙값에는 문장별 번역과 코드 추출을 포함하고 모델 초기화·다운로드·MiniLM 비교·파일 저장은 제외했다. 기존 직접 JSON 추출의 약 12.12초는 다른 8문장 세트의 수치이므로 같은 시험의 엄밀한 속도 비교가 아니다. 다만 같은 짧은 아이폰 예문에서는 사용자 실행 로그상 직접 추출 약 12.08초, 통번역 약 2.68초였다.

10/20은 번역 정확도가 아니다. 예를 들어 “색이 기억나지 않아요”를 “It's not glowing”으로 잘못 옮긴 문장도 색 필드가 빈 배열이면 이 검사에서는 통과한다. 자유 문장 의미 검토가 반드시 필요하다.

## 주 그룹에서의 목표별 정책 판정

다음은 requires_review 제한을 적용하기 전의 실험 판정이다. 실제 확정·로봇 동작은 수행하지 않았다.

| 질문 종류 | 건수 | 정책 결과 |
|---|---:|---|
| 목표 물품이 있는 질문 | 14 | 목표 선택 7, 보류 4, 일치 없음 3 |
| 기대 조건과 맞는 물품이 없는 질문 | 4 | 일치 없음 3, 잘못된 선택 1 |

조건을 잘못 번역했는데도 목표가 선택되거나, 틀린 색 때문에 우연히 no_match가 나온 경우가 있다. 따라서 목표 선택·거절 결과만으로 전처리 성공을 판단하지 않는다.

## 평가와 다음 단계

번역과 조건 추출을 분리한 구조는 실제 중간 문장을 확인할 수 있고, 일부 간단한 문장에서 짧은 응답 시간과 정보 보존 개선을 보였다. 하지만 현재 0.6B 모델은 색 오류·내용 누락이 반복돼 자동 확정용으로 채택할 근거가 부족하다.

실패는 세 층으로 나뉜다.

1. 번역: 남색→분홍, 노랑→빨강, 부정·불확실성 의미 변형.
2. 코드 추출: battery처럼 넓어진 품목명, 본체·화면 색의 관계, 복잡한 부정 범위.
3. 매칭: no damage 같은 자유 특징의 부정이 코사인 유사도에 묻혀 반대 물품을 선택.

단순히 최저 점수를 낮추거나 검토 제한을 해제하지 않는다. 번역 후보를 같은 문장과 신규 문장으로 비교하고, 손상 유무 등 중요한 부정 조건의 구조화·별도 비교를 검토해야 한다. 규칙 확장은 어휘 추가만으로 문맥 이해를 대체하지 않는다는 점을 함께 평가한다.

## 재현과 결과 위치

```powershell
& ..\.venv-query\Scripts\python.exe -u -m matching.evaluate_translation --offline
```

입력: [translation_20_cases.json](../configs/translation_20_cases.json). 로컬 상세 결과는 outputs/matching/translation_20/REPORT.html, REPORT.md, results.json에 저장했다. 각 문장의 실제 번역, 기대 조건, 추출 오류와 모든 11그룹의 후보별 점수를 포함한다. 같은 출력 폴더로 재실행하면 덮어쓴다. 이번 결과와 신규 코드·문서는 아직 커밋·푸시하지 않았다.
