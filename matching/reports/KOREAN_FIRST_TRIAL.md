# 한국어 근거 추출 → 사전 변환 → 자유 구절 번역 실험

실험일: 2026-11-04. 기존 통번역 결과를 보고 한국어에서 정해진 속성을 먼저 추출하는 대안을 구현했다. 한국어 추출은 Qwen 언어 모델이 아니라 사전·규칙으로 수행한다. 모델을 한국어 추출과 번역에 두 번 호출한 실험과는 다르다.

## 방법

1. 한국어에서 품목·색·스티커 유무를 찾고 원문의 정확한 start/end 위치와 구절을 저장한다.
2. 아이폰→phone, 남색→navy, 스티커 없음→absent처럼 사전으로 변환한다. 후보 데이터는 추출에 제공하지 않는다.
3. 부정된 색과 화면·케이스 등 구성요소 색은 별도 근거로 남긴다. 남색인지 검정인지 같은 대안 표현은 색을 확정하지 않는다.
4. 손상·위치·정도·스티커 설명은 원문 절을 유지한 채 OPUS-MT로 번역한다. 단어를 각각 번역하지 않는다.
5. 원문에 있는 SanDisk·VOVA 같은 라틴 문자는 번역에서 사라지면 원문 그대로 보존한다. 아이폰 브랜드 정보도 사전으로 보존한다.
6. 한국어에 손상 진술이 있는데 번역문에 대응 표현이 없거나, 균열의 금이 gold로 번역되는 경우에는 경고한다. 이는 제한된 패턴 검사이며 의미 검증기가 아니다.

모든 원문 근거는 원문 부분 문자열과 일치하는지 코드 시험으로 확인했다. 근거가 원문에 있다는 사실만으로 해석·누락까지 정확하다고 보장하지는 않는다. 서술 대상이 복잡하거나 어휘 사전에 없는 표현은 추가 검증이 필요하다.

## 조건과 결과

기존 20문장, 후보 그룹 11개·특징 기록 22개를 재사용해 220회 비교했다. 한국어 규칙은 이 평가 문장과 과거 실패를 알고 개발했으므로 미공개 시험이나 독립 검증이 아니다. 결과를 올리기 위해 Qwen 원본 특징이나 매칭 가중치는 변경하지 않았다.

| 항목 | Qwen 전체 번역 후 영어 추출 | OPUS 전체 번역 후 영어 추출 | 한국어 규칙 먼저 + OPUS 구절 번역 |
|---|---:|---:|---:|
| 동일한 20문장의 세 속성 전체 일치 | 10/20 | 14/20 | 20/20 |
| 변환 중앙값(로딩 제외) | 2.52초 | 0.51초 | 0.26초 |
| 번역 모델 호출 횟수 | 20 | 20 | 16 |

세 속성은 category/colors/sticker_status다. 마지막 방식은 사전 처리만으로 끝난 4개 문장도 포함한 전체 20문장 중앙값이다. 따라서 모델 자체가 빨라졌다고 해석하면 안 된다. 모델 초기화·파일 저장·후보 매칭은 제외했다.

추가로 라틴 문자 보존과 손상 누락 경고를 넣기 전 실행도 v1_results.json으로 보존했다. 현재 결과는 같은 세 속성 20/20이며 번역 내용 자체가 수정된 것은 아니다.

## 좋아진 부분

- 번역의 남색·빨강·검정 오역이 있어도 해당 조건은 원래 한국어에서 사전으로 결정한다.
- 보조배터리가 side battery로 번역돼도 품목 조건은 power_bank로 유지한다.
- “검정색 아니고 흰색”과 “검정 화면”의 색 범위를 이번 예문에서 분리했다.
- “어디서 잃었는지 기억 안 난다”를 색이 불확실하다는 뜻으로 취급하지 않는다.
- “뒷면이 많이 깨졌다”를 번역하기 전 한국어 근거에서 확인할 수 있다.

## 해결되지 않은 부분

- 남색 포켓몬 폰의 자유 구절은 여전히 dark cell phone / pocket-mon처럼 번역됐다. 색 조건이 맞아도 자유 문장 충실성은 별도다.
- “금이나 파손이 없다”는 no gold or damage로 번역됐다. 한국어 색 조건에는 gold가 들어가지 않지만 자유 문장에는 오역이 남는다.
- 긴 구어체에서 번역문이 I don't know where I lost it.만 반환해 파손이 누락됐다. 누락 경고를 기록했다.
- 일부 구절이 broken backs처럼 어색하게 번역된다.
- 규칙이 조건을 먼저 맞춰도 기존 Qwen의 USB 색 오인식, 스티커 오인식과 품목 other 문제는 해결하지 않는다.
- “파손 없는 흰색 아이폰”은 제한 전 정책에서 파손된 폰이 선택됐다. 자유 특징 부정 처리 문제는 그대로다.

현재 주 그룹의 제한 전 정책 결과는 matched 12, 보류 6, 일치 없음 2다. 목표가 있는 14문장은 목표 선택 11·보류 3, 정답 없는 4문장은 일치 없음 2·보류 1·잘못된 선택 1, 모호한 2문장은 보류였다. 선택 결과만으로 전처리 정확도를 판단하지 않는다. requires_review 제한을 적용한 실제 최종 판정은 전부 보류이며 자동 동작은 수행하지 않았다.

  --offline --mode korean-first `
