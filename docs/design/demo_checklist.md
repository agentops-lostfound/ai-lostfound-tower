# 통합 시연 점검표 (11/13 발표용 · LF-18)

한줄 설명: 리허설과 발표 당일에 **켜는 순서 → 화면 배치 → 한 바퀴 흐름 → 막혔을 때 대체**를 위에서 아래로 따라 하는 한 장짜리 표.

- 기준: 가상 시연(`TOWER_SIM=1`) 한 바퀴 — 11/9 저녁 클라우드에서 실제 브라우저(Playwright)로 끝까지 돌려 확인함(아래 "확인한 결과" 칸)
- 실물 로봇 반환을 넣을지는 TBD(11/11 실물 시험 뒤 결정). 넣으면 3장 ③ 단계만 실물로 바꾼다 — 1-1 참고
- 11/10 바뀐 점: 가상 시연의 처음 물건은 **분홍 핸드크림 하나**(해운대역 습득, 보관 칸 R3-1, 번호 `A-…`), 열 순서는 왼쪽부터 휴대폰·보조배터리·핸드크림·카드지갑. 찾기 요청 취소 · [직원 확인 후 진행] · 잃어버린 역 '모름'이 생김(3장 ⑥~⑧)
- 자세한 설명은 `docs/design/virtual_demo.md`(4-4 발표 흐름 · 4-5 키오스크 사진) · `web/README.md`(화면 지도·키오스크 카메라)

### 1-1. 실물 로봇으로 바꿀 때만 (11/10 #203·#202, 두 PC)

- **기본은 넣지 않는다.** 아래 설정을 넣으면 ③ 본센터 키오스크 회수와 [직원 확인 후 진행]이 진짜 로봇을 움직인다
- 로봇 옆에 정지 수단을 확인한 사람이 있을 때만. 순서는 `docs/handoff/2026-11-10-showcase-taught-robot.md`(로봇 PC 원격 실행부 → 관제탑 `.env` 의 `TOWER_ROBOT_SEQUENCE=taught` 등 → 관제탑 다시 켜기)
- 처음에는 R1-1 휴대폰 한 칸만 허용(`--allow-slot`). 처음 물건인 분홍 핸드크림(R3-1)은 아직 허용 칸이 아니므로, 실물 시연은 휴대폰을 새로 접수해 R1-1 에 놓고 진행
- 실물 모드에서는 ②의 분실 신고만으로 로봇이 움직이지 않고, ③ 회수 버튼이나 직원 단추를 눌러야 움직인다

## 2. 화면 배치 (브라우저 탭 순서)

| 탭 | 주소 | 보여 주는 것 |
|---|---|---|
| ★ 통합 시연(11/10) | `/showcase` — 【F11】 전체 화면 | 키오스크·휴대폰 화면 + **DB 실시간 기록** + **AI 에이전트 흐름**을 한 화면에. 머리말 탭 1→2→3 이 아래 ①②③ 과 같은 화면이라, 이 탭 하나로 한 바퀴를 돌 수 있다(④ 로봇 작업대 = `/live`) |
| ① 해운대역 키오스크 | `/kiosk?machine=KIOSK-A&cam=server` (카메라가 안 되면 `&demo=1`) | 습득 접수 |
| ② 분실인 웹 | `/lost` | 분실 신고 · 확인 질문 · 찾기 번호 · 진행 상황 · 💬 AI 안내 |
| ③ 부산역 본센터 키오스크 | `/kiosk?machine=CENTER` | 회수(물건 꺼내기) |
| ④ 실시간 관제 | `/live` | 이야기 진행 · 메인 AI 대화 · 에이전트 대화 |
| ⑤ 직원 화면 | `/staff` | 제출보관함 교차 검증 · 정지/원점 |
| ⑥ 관리자 | `/admin` | 보관함·로봇 상태 |
| ⑦ Langfuse | 브라우저 별도 창 | 챗봇 에이전트별 판단 기록 |

- 통합 시연 화면에서 장면마다 볼 것(11/10): ① 습득 → `item` 표에 새 행, 사진 분석 뒤 품목·특징 칸이 채워짐, 보관 칸 배정 · 관제탑 에이전트 대화 ② 분실 신고 → 후보 검색(SELECT) 뒤 `claim`·`quiz_attempt`·`reservation` 저장, 💬 AI 안내로 물으면 챗봇 에이전트 흐름 ③ 회수 → `claim` 읽기(SELECT) → 상태 변경 → `return_case` 저장 · 메인 AI ↔ 로봇팔·DB·채점 에이전트
- 통합 시연 화면 머리말의 저장소 표시(11/10): **"팀 DB 저장 n건"** = 가상 시연 기록이 팀 DB(PostgreSQL)에도 저장되는 중(`start_tower.bat` 기본). "팀 DB 연결 안 됨" = Docker 의 팀 DB 가 꺼짐(시연은 메모리로 계속) · "메모리" = `nodb` 로 켰거나 직접 켬
- 저장된 것을 보여 줄 때: DB 칸의 [팀 DB 조회] → 방금 접수한 물건이 맨 위에(사진 · 접수한 역 · 발견 장소 · 상태). 가상 시연에서 로봇·보관 칸 상태는 가상 세계 기준이라는 점은 그대로 설명한다

## 3. 한 바퀴 흐름 (①~⑤ 11/9 저녁 실제 확인 · ⑥~⑧ 11/10 시험으로 확인, 화면 한 바퀴는 리허설에서)

| 단계 | 화면 · 누를 것 | 확인한 결과(가상 시연) |
|---|---|---|
| ① 습득 | ① 키오스크: 물건 놓기 → 5초 뒤 자동 촬영(안 찍히면 [지금 찍기]) → 발견 장소(예: 승강장) → [다음] → 연락처 [건너뛰기] | "접수되었습니다 · 접수 번호 A-20261109-0001" · [접수 번호 복사] |
| ② 분실 신고 | ② `/lost`: 종류·색 → 역(처음 물건 분홍 핸드크림이면 "해운대", 모르면 "모름") → 이름·신분증 뒤 첫 자리 → 동의 → [분실 신고하기] | 찾기 번호 C-…, "확인 질문 통과! 오늘 부산역 본센터 방문으로 예약", 신분증 뒤 첫 자리(예: 1) |
| ③ 회수 | ③ 본센터 키오스크(처음부터 [물건 찾으러 왔어요] 탭) → 찾기 번호 + 신분증 뒤 첫 자리 숫자 하나 → [물건 꺼내기] | "물건을 꺼냈어요 · 제출보관함 앞에서 직원이 한 번 더 확인" · `/live` 로봇 반환 진행 |
| ④ 교차 검증 | ⑤ `/staff` [확인 시작] → 실물 [같음] · 신분증 [맞음] · [들었음 → 답 보기] → [일치] → [확인 결과 저장] | "✅ 인계 완료 — 물건을 분실인에게 건네세요" |
| ⑤ 챗봇 | ② `/lost` 💬 AI 안내: "분홍 핸드크림 잃어버렸어요" → 후보 → [분실 접수하기] 대화 | 대화로 접수 · Langfuse 에 coordinator → planner → supervisor ⇄ 일꾼 기록 · '지갑'이라고 하면 카드지갑으로 안내하는 한 줄이 붙음 |
| ⑥ 역을 모를 때(11/10) | 잃어버린 역 질문에 "모름"(선택지: 서면 · 해운대 · 부산역 · 모름) | 장소는 확인 질문에서 빠지고 **색**으로 확인 |
| ⑦ 직원 확인으로 진행(11/10) | 방문 대기 중인 찾기 요청 → `/live` 처리 현황 또는 `/showcase` 찾기 요청 카드 [직원 확인 후 진행] | 확인 질문이 틀렸어도 직원 대면 확인으로 반환 시작(동의·본인인증은 대신하지 못함) |
| ⑧ 찾기 요청 취소(11/10) | 방문 전 찾기 요청 → [찾기 요청 취소](`/live`·`/showcase` 직원 단추는 두 번 눌러 실행, 또는 분실인 웹 `/lost`) | 예약이 cancelled, 물건은 같은 칸에 그대로 |
| DB 보여 주기 | DBeaver 에서 `item_status_log` 를 물건 번호로 조회 | 한 바퀴면 7줄(kiosk → staff → tower → staff). 표별 변화는 `docs/design/db_change_flow.md` |

- 가상 시연 반환 한 번 약 20초(`TOWER_SIM_SPEED=1`), 발표 때 빠르게 하려면 `0.5`
- 키오스크 사진 습득은 Qwen 작업자가 있어야 특징이 채워진다. 없거나 늦으면 180초 뒤 "사진 분석 결과 없음 — 직원 확인"(가짜 특징으로 진행하지 않음)

## 4. 막혔을 때 대체

| 막힌 곳 | 바로 할 일 | 말로 설명할 것 |
|---|---|---|
| 키오스크 "카메라 점검 중" | 주소 끝을 `&demo=1` 로 바꿔 가상 카메라 | 서버 카메라 번호 확인 `python tools/list_cameras.py`(관제탑 끈 상태) |
| 사진 분석이 안 옴 | 미리 데운 Qwen 작업자 확인, 안 되면 `/live` 시험 입력의 [습득 신고]로 진행 | 결과 없으면 직원 확인으로 넘기는 안전 규칙 |
| 분실 신고가 "직원 확인"으로 끝남 | 정상 장면 — 닮은 물건·후보 여러 개면 자동 반환하지 않음 | 엉뚱한 물건을 돌려주지 않는 규칙 |
| 확인 질문이 틀림(다른 역을 말함) | 키오스크가 "본센터 직원에게 찾기 번호와 신분증을 보여 주세요" → `/showcase` 찾기 요청 카드 [직원 확인 후 진행] → `/staff` 교차 검증 칸에 "확인 질문 ⚠️ 맞지 않음"·"분실인이 말한 역" | 직원 대면 확인이 확인 질문을 대신 |
| 신분 번호가 틀림 | 키오스크는 반환을 시작하지 않고 기다림(3번 틀리면 잠금 → 본센터 직원 확인) | 본인 확인 안전장치 |
| 로봇이 멈춤 | `/staff` 🛑 정지 → 주변 확인 → 원점 복귀 | 정지는 언제든, 원점은 확인 후 |
| 관제탑이 멈춤 | 관제탑 창 Ctrl+C(3초) → `.\tools\start_tower.bat lan` → 화면 탭 새로고침 | 가상 시연 기록은 메모리라 다시 켜면 처음부터 |
| 챗봇 답이 느림 | 기본 안내 질문으로 바꿔 보여 주기 | 모델 판단은 규칙 목록 안에서만 — 실패하면 규칙 결과 |
