# 통합 시연 영상 촬영·편집 체크리스트

- 작성 기준: 2026-11-12, 팀 검토 반영
- 목표 길이: 약 7분 15초(전체 6~8분 목표)
- 형식: 내레이션 없이 자막 중심. 내레이션은 나중에 추가 가능
- 체크 기준: 촬영·자료 확보 및 편집 완료 여부. 기능 구현 완료 여부와는 별도
- 음성 검색·채점 에이전트·자동 재개는 영상에서 제외
- 정상 인계는 직원 없이 진행하고, 직원은 예외에만 개입

## 촬영 전 준비

영상 장면과 별도로 관리할 작업이다.

- [ ] 교육원 관제탑 최신 main 반영 확인 — 키보드 칸 가림 수정 #263 포함
- [ ] 화면에 옛 채점 에이전트가 나오지 않는지 확인
- [ ] 1920×1080으로 녹화 설정
- [ ] 이름·전화번호 등은 가짜 값 사용
- [ ] 로봇 작업자 탭의 **[기본 세팅]**으로 초기 상태 준비
- [ ] 실물 촬영 시 정지 수단을 확인한 작업자 배치
- [ ] 기존 검정폰·립밤 영상 중 재사용할 구간 선정
- [ ] 기존 가상·실제 1~8번 영상의 누락 구간 확인
- [ ] 장면마다 `[실물]`·`[가상]`·`[화면 녹화]` 태그 삽입 — 함께 보이면 병기
- [ ] 재사용 로봇 영상에는 **‘사전 녹화’** 추가 표시

## 본편 구성

시간은 편집 목표이며 고정 제한은 아니다. 습득 등록·챗봇·회수·수령 장면을 먼저 확보하고 나머지를 채운다.

| 완료 | 시간 | 장면 | 핵심 자막 |
|---|---|---|---|
| ☐ | 0:00–0:15 | **오프닝:** 분실물 찾기의 불편 → 우리 구성 그림 | “접수부터 찾기·반환까지 하나로 연결합니다.” |
| ☐ | 0:15–1:10 | **습득 등록:** `/showcase` DB·에이전트 함께 보기로 촬영 → Qwen 분석 → DB 저장 | “사진에서 특징을 읽고, 접수 기록으로 저장합니다.” |
| ☐ | 1:10–2:10 | **챗봇:** 자연어 검색 → 부족한 정보 되묻기 → 찾기 신청 | “대화로 특징을 좁혀 찾기 신청까지 진행합니다.” |
| ☐ | 2:10–3:40 | **회수:** 본센터 본인 확인 → 메인 AI 결정 → 실제 집기·전달·HOME | “확인된 요청을 해당 보관 위치의 로봇 동작으로 연결합니다.” |
| ☐ | 3:40–4:10 | **무인 인계:** 사람이 꺼냄 → [물건 받았어요] → 인계 기록·칸 해제 | **“정상 인계는 직원 없이 진행합니다.”** |
| ☐ | 4:10–4:40 | **탑뷰·DB 비교:** 일치 → 물건 또는 기록 변경 → 다시 확인 | “실제 보관 상태와 DB 기록을 비교합니다.” |
| ☐ | 4:40–5:15 | **로봇 검증 모음:** 8칸 빠른 몽타주 + 대표 한 칸 가상·실물 나란히 | “8개 보관 위치의 동작을 확인합니다.” |
| ☐ | 5:15–6:40 | **예외 처리 3종:** 아래 체크리스트 참고 | “확인되지 않으면 보류하고, 예외는 직원이 처리합니다.” |
| ☐ | 6:40–6:55 | **근거 화면:** 평가 결과·실행 기록·테스트 결과 일부 | 각 자료의 시험 범위·조건을 짧게 표시 |
| ☐ | 6:55–7:15 | **마무리:** 구현 완료·실물 검증·미구현 범위 표 | “구현한 기능과 검증한 범위를 구분했습니다.” |

습득 등록은 **Qwen 사진 분석 카드·DB 실시간 기록·에이전트 대화**를 `/showcase`의 **[DB·에이전트 함께 보기]** 한 번의 녹화로 확보한다. 챗봇 장면도 같은 화면 구성으로 기록한다. AI 협업을 위해 같은 접수 장면을 별도로 반복 촬영할 필요는 없다.

## 예외 처리 — 반드시 확보할 3개

- [ ] `[가상][화면 녹화]` **확인 질문 미통과 → [직원 확인 후 진행]**
  - 자막: “확인 질문을 통과하지 못하면 직원 대면 확인으로 전환합니다.”
- [ ] `[가상][화면 녹화]` **분실 메시지 끝 `#흐린촬영` → 매칭 보류 → 메인 AI 협업**
  - 자막: “판단이 어려우면 추가 근거를 확인하고, 바로 확정하지 않습니다.”
- [ ] `[가상][화면 녹화]` **정지 → 중단 이유 표시 → HOME → 다음 명령**
  - 자막: “중단 상태를 확인하고 복귀한 뒤 다음 작업을 진행합니다.”
