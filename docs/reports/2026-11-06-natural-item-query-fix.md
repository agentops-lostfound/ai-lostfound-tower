# LF-5 인사·짧은 물건 설명·색상 누락 수정

사용자 제보: `반갑다`, `녹색 반지갑`, `녹색 반지갑 찾아` 순서에서 인사·짧은 설명을 이해하지 못하고 녹색 조건 없이 검정 지갑을 반환했다. 모델 앞단의 규칙 기반 처리 문제이며 모델 연결 성공과 자연어 이해 품질을 구분해야 한다.

## 변경

- 반갑다·반가워·반갑습니다 등 인사 표현을 처리한다.
- 품목·색상·형태로만 구성된 짧은 설명도 검색 의도로 처리한다. 사용법 등 설명형 질문을 모두 검색으로 돌리지 않는다.
- 녹색·그린·green을 팀 표준 초록으로 정규화하고 적색·청색·황색 등 동의어도 추가했다. 공유 계약의 색상 목록은 변경하지 않았다.
- 인식하지 못한 색상 표현은 경고·재질문하며 색상 조건 없이 조회하지 않는다. `검색`·`탐색`의 마지막 글자를 색상으로 오인하지 않도록 제외한다.
- 응답에 실제 조회 조건 `품목: 지갑 · 색상: 초록`을 표시한다. 반지갑·장지갑 같은 형태는 현재 DB 검색 조건에 적용하지 않는다는 제한을 명시한다.

## 검증 및 적용

- 제보 재현과 동의어·짧은 설명·미지원 색상·검색 단어 구분 회귀 시험 6건 추가. 수정 전 실패, 수정 후 통과.
- 통합 Python 전체 808건, 실패 0, 건너뜀 14. LF-5 전체 803건, 실패 0, 건너뜀 13. 환경 의존 PostgreSQL 등 건너뛴 시험을 통과로 계산하지 않는다.
- 두 로컬 서버를 재기동했다. 실제 8111·8112 HTTP 경로에서 제보한 세 문장을 순서대로 재검증했다. 인사는 answered, 두 물건 질문은 category=지갑·color=초록·후보 없음이다. 현재 가상 DB에 초록 지갑이 없으므로 검정 지갑을 반환하지 않는다.
- 원본 사진·실제 팀 DB·회수 기록·로봇·GitHub·Jira·main은 변경하지 않았다.

이 수정은 알려진 표현 처리와 색상 누락 방지를 개선한 것이다. 임의의 자유로운 문장을 이해하는 의미 기반 의도 분석·검색을 완성했다는 뜻은 아니다.
