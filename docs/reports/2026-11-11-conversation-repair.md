`agents/chat_turn.py`의 제한된 의도 판정은 사용자 말만 참고한다. 사용자 확인 버튼의 초안 버전·확인 토큰, 검색 권한과 인증 검증은 기존 코드가 계속 검사한다. 이 판정으로 접수 저장이나 인증 권한을 만들지 않는다. 중요한 의도는 모델이 다른 답으로 바꾸지 못한다.

위젯 양식에는 실제 개인정보 입력 금지 문구와 가상 이름·가상 신분증 숫자라는 라벨을 표시한다. 원문 이름 대신 가린 값만 요청에 포함하는 기존 동작을 Node 테스트로 확인했다. 승인 지식 JSON과 기존 평가 문항·정답은 수정하지 않았다.

## 적용 범위

로컬 기능 브랜치의 소스 수정이다. 현재 사용 중인 브라우저 서버에 반영되었다고 확인하지 않았다. 이 작업 경로의 코드를 사용해 서버를 실행·재시작해야 새 동작을 볼 수 있다. 다른 원본 폴더를 실행하면 이 수정이 포함되지 않을 수 있다.

현재 운영 품목은 휴대폰·보조배터리·핸드크림·립밤이며 지갑 접수는 지원하지 않는다. 실제 운영 인증 공급자·운영 DB 연결 미완료 상태도 이번 수정으로 완료되지 않는다. 자유 대화 전반의 이해 성능이나 실제 모델 품질 향상을 이 테스트 결과로 주장하지 않는다.
