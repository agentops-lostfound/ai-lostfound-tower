# LF-5 미지원 이름·불만·반복 발화의 인사 루프 수정

사용자가 제보한 10턴 전체 대화에서 모르는 이름과 불만·한 글자 반응을 모델이 인사로 분류해 환영 문구를 반복했다. 종전의 유한한 시뮬레이션 통과로 이 대화가 검증됐다고 볼 수 없으므로 제보 전체를 새로운 회귀 시나리오로 추가했다.

## 변경

- 모델이 인사를 제안해도 실제 인사·감사·감정 표현의 근거가 없으면 환영 문구를 사용하지 않는다.
- 미확인 물건 이름에 대한 분실 발화는 그 이름을 검색 품목과 연결하지 못했다고 안내한다. 반복 설명에는 구매처만으로 품목을 정하지 못한다는 제한과 지원 6종을 명확히 안내한다. 얼박사의 실제 상품 종류를 추측하지 않았다.
- 욕설·불만, 한 글자 반응과 반복, 범위 안내 뒤 ‘그래?’를 별도 처리한다. 한 글자 반응 자체로 검색을 시작하지 않는다.
- 불만 문장에 명확한 지원 품목 검색이나 이용 질문이 함께 있으면 그 요청을 처리한다. 이름 인식 실패 뒤 정상 품목을 제시해도 검색할 수 있다.
- 인증·동의·물건 상태·DB·로봇 권한은 바꾸지 않았다.

## 검증

- 새 회귀 시험 5건: 전체 제보 대화, 품목 정정, 불만과 검색·안내 혼합, 분실과 입력 안내 혼합, 잘못된 모델 인사 제안 차단.
- 실제 모델 시뮬레이션 78/78 통과. 통합 Python 829건 실패 0·건너뜀 14, LF-5 Python 824건 실패 0·건너뜀 13.
- 두 실행 서버 8111·8112를 재시작하고 각각 제보 10턴 전체를 요청했다. 저장된 검증 답변과 일치하며 검색이 한 번도 실행되지 않았다. 화면 GUI 조작 시험은 아니다.
- 전체 실제 답변은 `2026-11-06-chat-dialogue-transcript.md`에 저장했다. GitHub·Jira·main은 변경하지 않았다.

이 검증은 추가한 유한한 대화의 회귀 결과다. 임의의 모든 상품명·은어·문맥을 이해한다는 뜻은 아니다. 아직 모르는 이름을 지원 품목으로 연결하려면 사용자 확인이 필요하다.
