결과보고서 양식 재검토 및 편집 판단 — 2026.11.12

1. 실제 양식 확인
한글 2024에서 열려 있는 결과보고서 24쪽을 주요 항목별로 확인하고, 파일 내 전체 본문을 추출하여 대조하였다. 사용자가 이미 표지를 일부 수정한 열린 문서와 디스크의 예시 파일 내용은 일부 다르므로 열린 문서에 직접 쓰거나 저장하지 않았다.

원래 대항목은 6개다.
1. 프로젝트 개요
   가. 프로젝트 목표 및 기대 효과
   나. 프로젝트 선정 이유
      1) 로봇 산업의 성장
      2) 서비스 로봇에 대한 투자와 중요성 확대
      3) 음료 제조기의 실효성 및 발전 방향
2. 팀원 및 임무 분담
3. 시스템 구조 및 사양
   가. 시스템 구조도
   나. PLC – CC-Link 구성
   다. 시스템 설비
   라. 세부사양 및 규격
4. 프로젝트 결과
   가. 공정 기획 — 공정 순서 / 공작물 제작
   프로젝트 일정
   공정별 — 순서도 / I/O List / PLC 래더도 / 로봇·비전 프로그래밍 / HMI 화면
5. 미비점 식별 및 검토 결과
6. 총평
붙임. PLC 래더도

앞선 답변의 문제: 개요의 하위 항목인 목표와 선정 이유를 독립 대항목으로 올려 8개 장으로 바꾸었다. 시스템 설비·세부사양과 공정별 프로그램 설명이 중복되었고, 양식의 시각 자료 중심 구조에 비해 긴 설명문이 많았다.

2. 이번 편집 원칙
- 6개 대항목과 '가·나 / 1)·2)' 계층을 유지한다.
- 개요에 긴 현황 나열 대신 목표·기대 효과를 짧게 쓴다.
- 선정 이유는 실제 유실물 서비스의 불편, 서비스 로봇 적용, 영상·언어 AI 발전과 우리 구현 범위로 연결한다.
- PLC/CC-Link는 HTTP API·로컬 IPC 통신 구성으로, I/O List는 실제 입출력·상태 계약으로, PLC 래더도는 프로그램 처리 흐름으로 바꾼다.
- HMI는 키오스크·웹·관제 화면으로 바꾼다.
- 시스템 설비에는 장비·모듈 구성만, 공정별 결과에는 동작과 개선 내용을 넣는다.
- 실물 동작 성공, 코드 구현, 고정 시험 통과, main 병합, 운영 서버 적용은 구분한다.
- 연우 최신 자료는 역할표, 챗봇 프로그램, 본센터 프로그램, 검증 붙임, 미비점에 분산한다.

3. 넣을 것
- 기존 구성도 3장, 작업대 실물 사진, 5공정 전체 흐름.
- 외부 배경 근거 3종: 서울시/서울교통공사 배송서비스 안내, IFR 2026 발표, Qwen3-VL 공식 자료.
- 구체적인 문제 해결 사례: 이전 접수 확인 재사용 방지, 응답 유실 시 완료 불명, 장소 표기·중복 처리, HOME 후 다음 명령 상태, 탑뷰 결과 무효화.
- 대표 실물 근거: R1-2/R4-1/R4-2 11단계 도착·HOME, 탑뷰 지정 프레임 및 DB 변경 감지.
- 대표 고정 대화 결과 6/20→20/20과 통합 시험 범위.

4. 본문에서 뺄 것 또는 붙임으로 옮길 것
- 예시의 PLC·인버터·유량 장비·바리스타 사진·과거 지원 사업 수치.
- 조사 근거 없는 처리 시간 절감률, 반환율 개선, 인력 절감률.
- 누적 시험 수의 합산, 일반 정확도 100%, 3,500개 신규 시험이라는 표현.
- ZIP 크기·CRC·전체 SHA256·18파일 상세·중간 커밋 나열은 붙임.
- Field Vision, SmolVLA/ACT, 자동 재개를 현재 기본 운영 완료로 소개하는 표현.
- SO-101의 미확인 가반하중·정밀도·최대속도 및 PC/GPU 대수 추정.

5. 필요한 자료
필수: 작업대 전체 사진, 접수 AI분석/DB 화면, 검색·확인 대화, 탑뷰 비교, 로봇 연속 사진, 수령 완료 화면.
권장: 대표 오류→수정 후 화면 1세트, Langfuse 버전/실행 추적 1장, 검증 결과 표.
추가 확인: 최종 PC/GPU·카메라 모델/실제 대수, 11/13 최종 실물 종단 결과, Field Vision 담당·실행 원본. 미확인 상태에서 숫자나 성공을 만들지 않는다.

7. 외부 자료 주의
- IFR 2026 수치는 2025년 공급업체 표본 조사. 238개 응답 업체, 전체 산업 추정치가 아니며 연도별 표본이 다르다. 서로 다른 연차 총량을 연결한 성장 그래프는 만들지 않았다.
- 서울시의 2025년 서비스 도입 안내는 당시 시행 사실과 접근성 문제의 근거로 사용한다. 우리 시스템이 해당 서비스나 경찰 시스템에 연결되었다고 쓰지 않는다.
- 서울시의회 PDF에는 '최근 3년간(22~25년)' 표기 자체가 모호하고 일부 다른 자료는 센터 이관분만 집계한다. 분모가 다른 반환율과 접수 건수는 이번 본문에서 제외했다.
