결과보고서에 넣을 실제 사진·화면 캡처가 필요합니다. 구성도·순서도·표는 준비됐고, 아래 자료를 채우면 됩니다.

1. 작업대·보관함
- 작업대 전체 / 8칸 보관판 / 제출보관함

2. 습득 등록·입고
- 습득물 등록 화면
- Qwen 사진 분석 결과 + DB 기록
- 본센터 회수·도착 처리 화면

3. 탑뷰·DB 비교
- 실제 보관 상태와 DB가 일치하는 화면
- 물품 위치·개수 변경 후 불일치 또는 재검증 화면

4. 챗봇 검색·찾기 신청
- 물건 설명 입력 → 추가 질문 또는 설명 정정 → 최종 확인 → 신청 완료

5. 로봇 반환
- 접근 → 집기 → 제출보관함 전달 → HOME 장면
- 같은 작업의 관제탑 단계 진행·완료 화면
- 오류 개선 사례에 사용할 중단 사유 화면도 있으면 좋습니다.

6. 수령·인계 완료
- 물건 받았어요 화면 / 해당 건의 인계 완료 기록
