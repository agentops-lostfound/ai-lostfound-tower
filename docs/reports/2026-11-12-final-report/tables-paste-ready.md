# 한글 표 10개 — 탭 구분 복붙용

표마다 코드 블록만 복사 → 한글 붙여넣기 → 내용 전체 선택 → 입력 → 표 → 문자열을 표로 → 분리 방법 지정: 탭 → 설정.

장비 [기입]은 확인 후 채운다. 11/13 일정은 11/12 기준 예정이다. close/open은 저장 자세명이며 단순 집게 명령과 구분한다.
