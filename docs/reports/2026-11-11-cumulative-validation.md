## 검증 원칙과 한계

기존 평가 원본·사람 판정·엑셀을 덮어쓰지 않는다. 기존 채점표/정답 기준도 임의로 바꾸지 않는다.
이전 결과의 무결성 검사와 최신 제품의 새 점수는 구분한다. 다른 버전 점수를 합산하거나 올려 적지 않는다.
누적 도구는 `.env`를 로드하지 않고 외부 인증/DB/클라우드 설정을 제거한 가상 환경에서 실행한다.
중단 파일은 `identity-evidence-work/stop-validation.flag`이며 다음 문항 전에 확인하고 부분 기록을 남긴다.
실제 DB·스키마·로봇·Langfuse production은 변경하지 않는다. 실제 인증 수집기와 네이티브 PostgreSQL 종단 검증은 별도다.
상세 설계: `docs/design/identity_evidence.md`.

무결성 원본: `docs/reports/cumulative-data-audit-20261111-01.json`.
무결성 검사는 소스 커밋 전 시행했으며 입력 파일별 SHA256을 남겼다. 최신 제품 성능 점수와는 구분한다.
원본 전체 Python 시험은 DB/인증/클라우드 설정을 비운 가상 환경에서 실행했다.
