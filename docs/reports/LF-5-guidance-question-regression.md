# LF-5 안내 챗봇 자체 질문 시험 및 보완

## 결과

수령·운영시간·기간·동의·신분정보·습득자 연락처·미확정 정책·복합 질문·물건 검색·범위 밖·지시문·개인정보 질문50개를 먼저 작성했다. 각 질문은 기대 응답 상태와 필수 근거 주제를 명시한다. 첫 실행은33/50, 실패17개였다. 수정 후 같은50개를 통과했고, 이어 작성한 추가 변형12개까지62/62가 회귀 기준을 통과했다.

이는 작성한 질문과 상태/출처 주제 회귀 기준에 대한 일치율이며, 의미 정확도100%나 독립 사용자 평가 결과가 아니다. 개발 중 같은 질문을 반복 사용했고 답변 전체의 모든 사실을 자동 채점하지 않는다. 원문·답변 문단의 의미 검수와 실제 사용자 질문 수집은 별도 필요하다.

## 발견·수정한 문제

| 문제 사례 | 이전 | 수정 후 |
|---|---|---|
| 토요일에도 하나요? / 운영시각 | 주제를 못 찾음 | 운영시간 확정값 미확인으로 보류 |
| 일요일 방문 가능? | 일반 수령 절차만 안내 | 방문 가능 시간은 보류 |
| 대리수령·수수료·예약 취소 | 일반 수령 절차로 충분한 것처럼 안내 | 해당 정책 미확정 안내 |
| 한 달 뒤 수령 / 물건 폐기 | 기간 의도를 놓침 | 기간·폐기 기준 보류 |
| 습득자와 분실인 기간을 함께 질문 | 습득자 규칙만 답함 | 습득자 규칙 출처 + 분실인 기간 미확정 분리 |
| 주운 사람 전화번호 보관 | 센터 연락처 문의로 혼동 가능 | 주어·기간에 맞는 연락처 규칙 적용 |
| 띄어쓰기·전각문자·제로폭문자 | 일부 의도·개인정보 패턴 누락 | NFKC 정규화, 제로폭 제거, 질문 공백 정규화 |

알아보기 어려운 오타는 임의로 교정해 사실을 만들지 않고 구체적인 재질문을 요청한다. 문맥을 이어받는 다중 턴 대화/일반 자유 문장 이해까지 구현한 것은 아니다. 운영시간·보관기간·대리수령·수수료·센터 연락처 등 실제 운영 정책을 새로 만들지 않았다.

## 재현

```powershell
python -m evaluation.evaluate_guidance --output guidance_result.json
python -m unittest discover -s tests
```

- 질문: evaluation/guidance_questions.json (작성한62개)
- 채점: evaluation/evaluate_guidance.py (응답 상태, 필수 출처 주제, 일부 잘못된30일 일반화 검사)
- 회귀 시험: tests/test_guidance_regression.py (질문 묶음 + 공백/유니코드 + 개인정보 우회)
- 최종 전체 자동 시험365개, 실패0, 조건부9개 건너뜀. 묶음 시험1개 안에서62개 질문을 순회하므로365와62를 더해 독립 시험 수로 표현하지 않는다.
- 실제 로컬 HTTP 서버에서 주말·대리수령·예약 취소·복합 질문·공백 변형6개도 확인했다. 외부 전송/DB 조회/실제 후보 검색은 하지 않았다.
- 작업 폴더 guidance_before.json/guidance_after.json에 실행별 상세 응답을 보관했다. 개인 사용자 질문을 수집한 자료는 아니다.
