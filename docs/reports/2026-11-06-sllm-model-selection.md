# LF-5 챗봇 소형 언어모델 조사·비교·적용

## 결정

이 PC와 현재 RAG 구성에서는 **Qwen3-4B-Instruct-2507, Q4_K_M**를 선택했다. Ollama 태그는 `qwen3:4b-instruct-2507-q4_K_M`, 실제 다운로드 크기는 2,497,293,803바이트다. 새 모델을 학습하지 않고 공개된 지시 학습 모델을 적용했다. 사진 모델은 기존 Qwen3-VL 2B를 유지하며 채팅 모델과 역할을 분리했다.

선정은 아래의 유한한 대화·시스템 구성에 대한 판단이다. 모든 한국어 질문에서 가장 좋은 모델이라는 뜻은 아니다. 기존에 보완한 서버 검색 조건·제한 처리는 유지하며, 답변을 정해진 문단에서만 고르는 방식 대신 **모델이 직접 문장을 작성하는 경로**를 추가했다.

## 환경

- NVIDIA RTX 3050, VRAM 6GB. 물리 RAM 약 15.4GiB(16GB급).
- 조사 시 여유 RAM 약 2.7GiB, 디스크 약 36.7GiB. 기존 모델·Windows 작업이 VRAM을 사용하고 있어 비교 모델을 순서대로 적재했다.
- Ollama 0.40.14, 로컬 API만 사용. 다른 앱·프로세스를 종료하지 않았다.
- 비교 설정: 4bit 모델, 컨텍스트 6,144, 비추론 응답, 생성 temperature 0.2/seed 42, 검사 temperature 0. 모델의 로딩 속도와 한국어 질문별 실제 응답 시간을 기록했다.

## 실제 비교와 선택 근거

동일한 합성 대화 22턴을 세 모델에 적용했다. 휴대폰·검정 부정·원숭이 키링·연보라색, 전각 USB·복수 색상·품목 전환, 까비 반응, 날씨 거절·그래, 미확인 상품명·욕설·반복 발화, 글 입력·운영시간, 우회 요청, 검색·수령 안내 혼합을 포함한다.

| 모델 | 선택 단계 자동 기준 통과 | 중앙 응답 시간 | 최대 응답 시간 |
|---|---:|---:|---:|
| 기존 Qwen3-VL 2B | 0/22 | 1.52초 | 3.72초 |
| Qwen3 4B Instruct-2507 | 20/22 | 3.05초 | 4.80초 |
| Qwen3.5 4B | 14/22 | 2.83초 | 4.59초 |

이 표는 **모델 생성 답변이 별도 적합성 검사와 상태·필터·출처 조건까지 통과한 파이프라인 결과**다. 원래 챗봇이 0개 질문에 답한다는 뜻이나 순수 모델 지능 점수가 아니다. 같은 모델을 답변 검증에도 사용하므로 모델별 검사 보수성·오탐이 수치에 영향을 준다. 검사기만으로 의미 정확도를 보장하지 못한다.

실제 문장도 읽어 검토했다. 초기의 모델 중심 JSON 검색 계획 실험에서는 잘못된 색상 추측·기능 오안내가 있어 적용하지 않았다. 다른 RAG 실험에서도 자동 상태가 맞아도 문장이 틀린 사례를 확인했다. 최종 경로는 **서버가 검증한 조회·제한·승인 문서를 우선하고, 대화 기록은 모델의 기본 user/assistant 역할 형식으로 전달**한다.

선택 단계 뒤에는 조회를 실행하지 않았는데 실행했다고 쓰는 표현을 추가 차단했다. 선정 모델 최종 22턴 재실행에서는 **20턴의 모델 답변을 채택하고 2턴은 서버 근거 답변으로 대체**했다. 이 단계의 기존 자동 기준은 19/22였으며 나머지 하나는 자연스러운 인사에도 `not_found`가 남은 메타데이터 문제였다. 이 메타데이터는 이후 단위 시험과 두 실제 서버에서 수정 확인했다. 두 대체 응답은 미지원 색상과 욕설 상황이며, 원문 대체를 ‘모델 생성 성공’으로 계산하지 않았다.

최종 선정 모델 재실행 중앙값은 3.01초, 최대 4.80초였다. 사전 적재+8토큰 짧은 응답 측정은 약 3.24초이며 전체 첫 상담 응답의 보장 시간이 아니다. 다른 GPU 작업·모델 교체 적재·PC 상태에 따라 달라진다.

## 적용한 구조

1. 서버가 기존 읽기 전용 검색·인증 확인·색상 제한·승인 문서 근거를 준비한다.
2. 선정 모델이 그 근거와 실제 user/assistant 대화를 받아 답변 문장을 작성한다. 일부 사실 안내는 원문과 비슷하게 작성될 수 있다.
3. 승인 출처·개인정보·허위 실행 표현·근거 없는 숫자를 확인하고, 모델 보조 검사로 사실 일치·질문 적합성을 점검한다. 검증 실패·혼잡·장애는 안전한 서버 근거 답변으로 돌아간다.

모델이 임의 SQL을 만들거나 인증·예약·접수·반환·로봇 동작을 실행하지 않는다. 실제 DB 검색은 기존 서버 인증이 준비되어야 한다. 원본 물건 ID·검색 참조·인증 토큰은 모델 입력에 넣지 않는다.

기존 서버의 규칙은 검색·권한 검증용으로 유지했다. 이것을 전부 없앴다고 보고하지 않는다. 자유 대화 생성으로 바뀐 부분은 `agents/model_chatbot.py`이며 `LF_CHAT_ENGINE=model` 또는 `--engine model`로 명시적으로 선택한다. 기존 모드는 비교·원문 대체와 회귀 시험용으로 남겼다.

## 실행·재현

```powershell
python -m tools.prepare_chat_models --model qwen3:4b-instruct-2507-q4_K_M
python -m tools.run_chat_widget_demo --engine model --model qwen3:4b-instruct-2507-q4_K_M
```

관제탑·설명 입력 서버 환경은 `LF_CHAT_ENGINE=model`, `LF_CHAT_MODEL=qwen3:4b-instruct-2507-q4_K_M`다. 비밀 설정 파일을 읽거나 수정하지 않았고 로컬 재시작 스크립트에 실행 환경값으로 적용했다.

모델 버전·다이제스트·설정은 `docs/guidance/chat-model-profile.json`, 선택 모델의 실제 답변은 `2026-11-06-selected-model-transcript.md`에 기록했다. 이 프로필은 재현용 기록이며 서버 설정을 자동 덮어쓰는 비밀 설정 파일이 아니다. 비교 원본과 탈락한 계획 방식은 `.cache`의 로컬 실험 자료이며 배포 코드로 쓰지 않는다.

## 검증·적용 확인과 한계

- 통합 Python 856건, 실패 0, 건너뜀 14. LF-5 Python 851건, 실패 0, 건너뜀 13. 실제 PostgreSQL 시험 등 환경 의존 검사는 이번에 실행하지 않았다.
- Node 화면 로직 41건 통과, 설명 입력 채팅 JS 구문 검사 통과.
- 모델 전용 회귀 시험: 실제 문장 반환·네이티브 역할 기록·출처 검증·서버 후보 유지·토큰 미전달·인증 불가·모델 장애·허위 시간·조회 실행 거짓 표현·비정상 검사 응답·인사 상태 수정.
- 두 로컬 서버 8111·8112를 선정 모델과 `engine=model_rag`로 재시작했다. 각 서버에서 인사→휴대폰→검정 부정→원숭이 키링→연보라색 5턴을 실제 HTTP로 확인했다. 각 서버 4개는 생성 답변 채택, 미지원 색상 1개는 서버 근거 답변으로 대체됐다. GUI 조작 검증은 아니다.
- 이전 질문 4개만 보내던 화면을 최대 8개 역할 메시지(4쌍)로 확장했다. 모델 입력 문맥은 총 2,200자와 메시지별 길이로 추가 제한하며 장기 대화 기억은 아니다. 새로고침·대화 지우기에서 기록을 지운다.
- 복수 색상·미지원 색조·키링 상세 검색이 DB에 새로 구현된 것은 아니다. 원문 대체와 부자연스러운 표현이 여전히 발생할 수 있으며 모든 질문 이해·무오류·모델 검증의 완전성을 보장하지 않는다.
- 화면·API·도구 변경은 모델 연결과 역할 대화 전송을 위한 지원 작업이다. 공유 계약은 변경하지 않았다. GitHub·Jira·main은 변경하지 않았다.
