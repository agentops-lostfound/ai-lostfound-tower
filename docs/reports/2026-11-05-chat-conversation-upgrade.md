# LF-5 챗봇 대화 이해 개선 — 정연우, 2026-11-05

## 변경

기존 챗봇은 정해진 표현에 의존했고 이전 질문을 전달하지 않았다. “검정 지갑 잃어버렸어”, “사진 첨부는 어디서 해?”, “그럼 빨간색은?” 같은 질문을 놓쳤다. 사진 질문에서도 모델이 없으면 사용 안내 전체를 반환했다.

- 일상 표현을 안내·검색 의도로 정규화한다. 인사·기능 질문에 응답하고 불명확한 질문에는 구체적인 예를 제시한다.
- 현재 화면의 이전 사용자 질문 최대 4개로 생략된 품목·색상·안내 주제를 보완한다. 새 주제는 이전 검색 조건을 이어받지 않는다. 색상 변경·재검색을 지원한다.
- 사진·음성·후보 검색 안내에서 관련된 원문 문단을 선택한다. 모델 미연결·실패 시에도 같은 기준과 주의사항을 유지한다. 모델이 관련 없는 문단을 선택하면 문서 답변으로 돌아간다.
- 앞선 질문 사용 여부를 표시한다. 대화 삭제, 확인한 설명 변경, 조건 지우기는 질문 맥락을 초기화한다. 질문 기록을 DB·localStorage에 보관하지 않는다.

## 보호와 한계

이전 질문은 최대 4개, 각 500자이며 현재 질문과 동일한 개인정보 검사를 거친다. assistant/system 역할이나 인증 상태를 전달받지 않는다. “인증 완료”라는 질문으로 실제 인증·동의 확인을 대신할 수 없다. 실제 DB 차단과 접수 ID 비공개를 유지한다. 운영시간·보관기간·배송 등 미확정 정책은 이전 대화로 확정하지 않는다.

일반 대화 모델로 전환하거나 가중치를 교체한 작업은 아니다. 로컬 Ollama 문단 선택형 RAG를 유지하며 지원 범위의 한국어 표현·이어 묻기·답변 집중도를 개선했다. 추가 특징 매칭·실제 인증 연동은 별도 작업이다.

## 검증

- 신규 대화 회귀 13개 메서드: 15개 일상 표현, 색상·품목 변경, 재검색, 여러 차례 이어 묻기, 주제 전환, 화면 간 격리, 입력 제한, 위조 기록·인증 주장, 비공개 번호 보호 포함.
- 전체 Python 490개 실행, 실패 0개·환경 조건 14개 생략. 이번 실행에는 실제 PostgreSQL을 연결하지 않았다.
- Node 자동완성 4개 및 변경 JavaScript 문법 검사 통과.
- 재시작한 API에서 인사·분실 표현·색상 변경·품목 변경·미확정 정책·사진 안내·인증 실패 이어 묻기 7개 확인. 사진 답변의 날짜·장소 추측 금지 유지와 불필요한 녹음 안내 제외 확인.
- 기존 62개 안내 회귀 중 인사는 의도한 개선에 맞춰 `not_found`에서 `answered`로 변경했다. 정책 보류·근거 규칙은 유지했다. 작성한 사례의 회귀이며 일반 대화 정확도 측정은 아니다.

## 사용 예

“검정 지갑 잃어버렸어” → “그럼 빨간색은?”은 지갑을 유지하고 색상을 변경한다. “USB는?”은 새 품목으로 전환하고 이전 색상·날짜·역을 해제한다. “본인 확인 꼭 해야 돼?” → “그럼 실패하면?”은 인증 안내 주제를 유지한다. 시연 DB 결과는 실제 습득물이 아니다.
