# LF-5 접수 안내의 실제 버튼 이름 보존

## 발견

`12558f2`의 실제 전체03회는 **500/500**으로 완료됐다. 보충 통합6/6·정책6/6·실사용 말투20/20도 통과했다.
다만 별도 안내 품질01회는 **9/10**이었다. 원본 `planner-midm-guidance-20261111-01.json`을 보존했다.

10번의 생성 답변에는 "요약을 확인한 후 접수"라는 순서는 있었으나, 화면의 실제 버튼 이름 `[접수할게요]` 대신 일반적인 "접수 버튼"만 있었다.
보충 채점표는 이 표현을 수락하지 않았다. 이를 확인 절차 자체가 전혀 없는 답으로 해석하지 않는다.
시작 버튼과 최종 확인 버튼을 구분할 수 있게 제품 안내의 명확성을 높였으며, 정답지의 허용 표현을 추가하거나 배점을 바꾸지 않았다.

## 변경

기존 생성 검사는 접수 안내에 `접수할게요`·`요약`·`확인한뒤` 중 하나만 있어도 통과시켰다.
승인 문서에 근거가 있는 경우 **실제 버튼 이름과 확인 절차를 각각 요구**하도록 분리했다.
문서에 없는 사실은 요구하지 않으며, 생성 답변에서 빠지면 승인된 안내 원문으로 대체한다.

- 같은 실제 실패 답변을 재현한 시험에서 일반적인 접수 버튼 안내를 거절하고 실제 버튼 이름을 보존했다.
- 버튼 이름만 남기고 확인 절차를 빼는 답도 거절했다.
- "요약을 확인한 후 [접수할게요]를 누르면 접수"라는 올바른 유사 표현은 생성 답변으로 허용했다.
- 승인 지식 JSON·서비스 안내 원문·평가 정답·배점은 변경하지 않았다.
