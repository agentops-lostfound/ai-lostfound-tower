# 정연우 · 촬영 객체와 접수 번호 연결의 내부 검사 준비

## 이번에 진행한 범위

실제 인증·예약·모델 정확도 검증에는 팀의 계약·데이터가 필요하다. 그 전에 독립적으로 진행할 수 있는 단일 촬영 장면과 물품 접수 번호의 연결 검증을 준비했다. `agents/scene_bindings.py`의 연결표는 **로컬 검사 제안 형식**이며 팀 공통 API 계약을 변경하거나 확정한 것이 아니다.

연결표에는 촬영 세션, 시간대가 있는 촬영 시각, 원본 결과의 SHA-256, `vision_id`와 `item_id`의 명시적인 일대일 대응을 넣는다. 번호는 객체 순서·품목·색상을 보고 만들어 내지 않는다.

## 적용한 검사

- 완료된 장면·모든 객체의 유효한 검출 및 성공한 Qwen 특징 필요.
- 1~50개 객체, JSON 2MB 제한·NaN 거절. 검사 시작 시 장면과 연결표 내용을 독립 불변 데이터로 보존.
- 모든 객체가 정확히 한 번 나타나고, 접수 번호 형식이 맞으며, 접수 번호가 중복되지 않아야 한다. 연결표 순서는 달라도 된다.
- 장면 해시·촬영 세션이 다르거나 촬영 시각이 미래/오래된 경우 거절. 보고서에 촬영 시각이 있으면 연결표 시각과도 일치해야 한다.
- 기본 유효 시간은 이 **검사 도구의 임시값 300초**이며 설정 가능하다. 운영기관의 보관·예약 정책이 아니다.
- 매칭 후 선택된 후보의 현재 재고 상태를 서버가 제공하는 콜백으로 확인한다. 확인기 없음·거절·예외는 전체 결과를 보류하고 예외 원문을 노출하지 않는다. 모델 실행·재고 확인 뒤에도 촬영 유효 시간을 재검사한다.

`Chatbot.inspect_inventory_matching`은 기존 실제 팀 한국어 파서·Qwen 브리지·HybridMatcher를 쓰는 검사 결과에 `inventory_link_checked`를 표시한다. 선택된 접수 번호는 내부 확인기에만 전달하고 결과에는 반환하지 않는다. 후보가 없거나 설명이 모호하면 재고 확인을 실행하지 않는다.

## 실행·검증

```powershell
python -X utf8 -m tools.check_scene_links
```

합성 장면만 사용하며 정상 재고·변경된 재고·촬영 만료를 확인한다. 사진·실제 DB·로봇·모델 다운로드는 사용하지 않는다. 신규 회귀 12개는 연결 순서·불변 복사본·중복/누락/다른 장면·시간대·만료·재고 확인 실패·매칭 중/확인 중 만료·비공개 ID 미노출을 검사한다.

## 여전히 필요한 팀 연결

- 실제 장면의 객체와 접수 물건이 같음을 보장하는 생산 절차, 촬영 세션의 유일성·시계 기준·유효 시간 합의.
- 서버 소유 연결표 공급과 실제 읽기 전용 재고 확인기. 같은 DB 스냅샷에서 여러 물건을 확인하는 거래 경계도 필요하다.
- 실제 본인인증·필수 동의·후보 선택·예약·반환 승인.

해시는 연결표와 장면 내용의 일치만 검사한다. 실제 물건의 정체·소유권·촬영 출처를 증명하지 않는다. `inventory_link_checked=true`도 인증·반환 승인이나 실제 DB 연동 완료가 아니다. 현재 모든 결과는 검사 전용이며 인증·예약·로봇 승인 값은 false다. 공개 HTTP·현재 위젯에는 연결하지 않았다.
