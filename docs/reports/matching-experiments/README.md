# 매칭 전처리 실험 목록

현재 잠정 기준은 E07(한국어 선추출)이다. [2026-11-04 결정·코드 기본값·남은 한계](../2026-11-04-korean-first-decision.md)를 참고한다. 독립 검증 완료나 자동 확정 허용을 뜻하지 않는다.

최종 실험 결과 보고서를 작성할 때 사용할 색인이다. 방식·데이터·지표가 다른 시험을 하나의 정확도로 합산하지 않는다. 먼저 입력 세트와 주 평가 그룹을 구분하고, 추출 속성·자유 문장 의미·후보 순위·확정 판단·시간을 각각 비교한다. 로컬 outputs 원본은 Git 제외이며 기능별 요약은 matching/reports에 둔다.

## 최종 보고서에 포함할 항목

- 문제와 가설: 어떤 오류를 어떤 변경으로 줄이려 했는가.
- 고정한 조건과 변경한 조건: 모델, 프롬프트·예시, 규칙, 입력, 후보, 가중치, 생성 설정.
- 데이터 출처와 독립성: 사진 정답인지 Qwen 기반 약한 정답인지, 중복·단일 후보·개발 노출 여부.
- 단계별 결과: JSON 성공, 속성 보존, 자유 특징의 부정·위치·정도·고유명사 보존, 오선택·보류·거절.
- 시간: 모델 로딩, 추출·번역, MiniLM 비교, 전체 요청을 구분. 모델 호출을 생략한 문장 수도 표시.
- 실패 사례: 결과가 우연히 맞은 경우, 번역 오류가 사전에 의해 가려진 경우, 자유 특징 모순이 높은 점수를 받은 경우.
- 적용 판단과 미구현: 자동 확정 제한, API 미실행 등 실제 상태를 명시.

세 속성 일치는 문장 의미 정확도나 실제 분실물 검색 정확도가 아니다. E03은 확인 필요 여부까지 검사한 8문장 시험이고 E04 이후는 세 속성의 20문장 시험이므로 직접 순위표로 묶지 않는다. E07의 규칙은 기존 문장을 보고 개발했으므로 별도의 신규 검증 세트가 필요하다.
