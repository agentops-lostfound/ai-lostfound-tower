# 정연우 · 가상 데이터 연동 검증 결과

## 실행 범위와 결과

현재 로컬 기능을 함께 연결해 검사했다. 추가한 통합 시험 4개와 기존 전체 회귀를 실행한 결과 Python **779개 실행·실패 0·환경 조건 1개 생략**, Node 화면 동작 **38개 전부 통과**다. 이번에는 제품 코드를 추가 수정할 연동 오류가 발견되지 않았다.

실제 팀 DB 대신 이름을 제한한 일회용 PostgreSQL 16 DB와 임시 SQLite를 사용했다. 직접 만든 검증 컨테이너는 종료·정리했다. 기존 로컬 시연 DB·팀 DB·실물 로봇·원본 사진은 변경하지 않았다. GitHub·Jira는 갱신하지 않았다.

## 새로 이어 본 흐름

| 시나리오 | 확인 결과 |
|---|---|
| 글 설명 → 확인 거절/승인 → HTTP 챗봇 검색 | 거절은 422, 승인 후 품목·색상·날짜·호선·역이 전달되고 가상 후보 조회 성공 |
| 생성한 PNG → 분석 대체 객체 → 확인 → 검색 | 같은 검색 계약으로 조회 성공, 공개 후보는 번호·품목·색상만 포함 |
| 생성한 WAV → STT 대체 객체 → 확인 → 검색 | 같은 검색 계약으로 조회 성공, STT 작업자 종료 확인 |
| 설명 확인 완료 → 미검증 토큰으로 PostgreSQL 검색 | authentication_required, DB 검색 메서드 미호출 |
| 문서 안내·미확정 운영시간 질문·개인정보 입력 거절 | 알려진 근거와 미확정 안내 유지, 가상 재고 변경 없음 |

사진·음성은 합성 파일과 명시적인 분석/STT 대체 객체를 썼다. 실제 YOLO/Qwen/STT 인식 성능을 측정한 것이 아니다.

## 동일 PostgreSQL에서 설명 확인·검색·촬영 연결·회수를 함께 검증

실제 팀 스키마와 `PostgresIntakeStore`, `CollectionStore`, `PostgresItemSearch`/`SearchAgent`, `Statistics`를 사용했다. `DescriptionService`와 챗봇 입력/검색은 FastAPI TestClient의 HTTP 경로로 연결했다. 인증 검증기는 합성 시험 세션만 인정하도록 주입했다.

| 물류 단계 | HTTP 검색 후보 | 촬영 후보 2개의 재고 연결 검사 |
|---|---:|---|
| 검정 지갑 2개 접수 | 2 | 통과 |
| 2개 회수 중 | 0 | 보류 |
| 1개만 본센터 도착 | 1 | 보류 |
| 모두 본센터 도착 | 2 | 통과 |

각 단계의 촬영 장면과 연결표는 새 합성 입력으로 명시 제공했다. 부분 도착에서 촬영 검사 전체가 보류되는 것은 후보 2개 중 1개가 아직 이동 중이기 때문이며, 안전한 정상 동작이다. 자동으로 한 물건을 확정하지 않는다.

이전 회수·통계 통합 시험도 함께 실행하여 접수 통계가 전 단계에서 2건으로 유지됨을 검증했다. 새 흐름에서 중복 회수는 같은 회수 번호를 반환하고, 도착 재전송으로 이력이 중복되지 않으며, 최종 이력 6건·미해결 알림 0건을 확인했다. 검색·촬영 검사 결과에는 실제 접수 ID·비공개 특징을 노출하지 않고 인증·예약·로봇 승인도 부여하지 않았다.

장소 페이지·중복 방지·가상 기록 점검·삭제·시간 초과·재시도 맥락·늦은 응답 격리는 기존 Python/Node 회귀에 포함되어 통과했다.

## 재실행

```powershell
python -X utf8 -m tools.check_center_postgres
node --test tests/test_chat_widget.cjs tests/test_collection_desk.cjs tests/test_demo_statistics.cjs tests/test_demo_places.cjs tests/test_demo_audit.cjs tests/test_guidance_suggestions.cjs
```

새 시험은 `tests/test_virtual_workflow.py` 3개와 `tests/test_center_postgres.py`의 HTTP/촬영 연결/물류 통합 1개다. PostgreSQL 시험은 도구가 만든 임시 DB 설정이 있어야 실행된다. 준비 코드의 회수 스키마는 pending 위치를 유지하고 시험에서만 명시 적용한다.

## 아직 검증하지 않은 범위

실제 브라우저·모바일·스크린리더 조작, 실제 모델 정확도, 팀 인증 서버, 실제 팀 DB 권한/운영 데이터, 물리 객체↔접수 ID 공급 절차, 예약·반환 승인·실물 로봇은 별도 검증이 필요하다. 현재 테스트 통과를 전체 운영 시스템의 무오류 보장으로 해석하지 않는다. 촬영 연결 검사는 공개 HTTP/위젯에 아직 연결하지 않았다.
