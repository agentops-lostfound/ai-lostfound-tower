# LF-5 설명 입력·웹 안내 챗봇 화면 개선

## 변경 내용

- 큰 화면은 왼쪽 설명 입력, 오른쪽 고정 안내 채팅으로 구성한다. 작은 화면에서는 세로로 배치하고 안내 도우미 이동 버튼을 제공한다.
- 추천 질문 카드 세 개, 입력 키워드 자동완성, 방향키 선택, Enter 전송과 Shift+Enter 줄바꿈을 지원한다. 한글 조합 중 Enter는 전송하지 않는다.
- 답변은 말풍선과 근거 문서 펼쳐보기로 표시한다. 채팅 내부만 스크롤하며, 전송 실패 시 재시도 버튼을 제공한다.
- 대화 지우기는 현재 화면의 채팅만 지운다. 물건 설명 입력은 유지한다. 질문과 대화를 브라우저 영구 저장소에 기록하지 않는다.
- 추천 질문 순서는 사전에 정한 질문의 선택 횟수만 서버 메모리에 집계한다. 최초에는 고정 추천 순서이고, 집계 후에는 '이번 서버 실행 기준'을 표시한다. 서버 재시작 시 초기화되며 장기간 이용 통계가 아니다. 자유 입력 질문은 순위용으로 저장하지 않는다.
- 운영시간·보관기간 등 미확정 정책은 계속 확정 자료가 필요하다고 안내한다. 안내 챗봇은 실제 물건 검색을 하지 않는다.

## 변경 범위

`web/lost-input/`에 화면과 정적 파일을 구성했다. 화면을 제공하고 추천 질문 집계를 연결하기 위해 `agents/lost_api.py`, `agents/guidance.py`도 수정했다. 기존 품목·날짜·장소 입력 계약은 바꾸지 않았다.

## 검증

- `python -m unittest discover -s tests`: 369개 실행, 실패 0개, 환경 조건으로 9개 생략.
- `node --test tests/test_guidance_suggestions.cjs`: 자동완성 관련 시험 4개 통과.
- 세 JavaScript 파일 문법 검사 통과.
- 실제 브라우저에서 추천 질문 즉시 전송, 개인정보 자동완성 방향키 선택과 전송, 대화 초기화, 기존 설명 입력 결과를 확인했다.
- 1440×1000과 375×812 화면에서 배치를 확인했다. 작은 화면의 가로 넘침이 없고 채팅 입력창을 사용할 수 있다. 브라우저 오류 로그 없음.
- '햄스터 키링 달린 검은색 휴대폰' 입력 결과에서 모형폰·검정·햄스터 키링이 정리됨을 확인했다.
