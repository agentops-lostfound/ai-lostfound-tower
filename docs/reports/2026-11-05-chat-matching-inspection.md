# LF-5 정연우 · 설명 입력에서 LF-20 매칭으로 검사 연결

## 구현과 사용

`Chatbot.inspect_matching(question, report, inspector=None)` 내부 메서드와 `agents/matching_inspection.py`를 추가했다. 원래 사용자 문장을 개인정보·길이 검사한 뒤 팀 `KoreanFirstParser` → `inspect_sequence.inspect` → `QwenMatchingPart` → `HybridMatcher`로 전달한다. 한국어 원문의 품목·색상·스티커 조건을 번역기가 덮어쓰면 확인을 요청한다.

기본 실행은 모델을 로드하거나 내려받지 않는다. 품목·색상 비교는 실제 팀 정책으로 수행하고, 상세 문장 번역이나 영문 특징 임베딩이 필요하면 `feature_models_required`로 보류한다. 명시적으로 준비한 `KoreanFirstParser(offline=True)`와 `HybridMatcher(..., offline=True)`를 주입할 수 있지만, 실제 모델 성능 검증은 이번 범위가 아니다. 현재 검사 연결의 기본 번역기·임베딩은 미구성이다.

저장소에서 같은 시험 환경 Python으로 실행한다:

```powershell
python -X utf8 -m tools.check_chat_matching
```

이 명령은 코드에 정의한 가상 장면만 사용하며 실제 사진·DB·로봇을 읽거나 실행하지 않는다.

## 확인 결과

| 질문 유형 | 결과 |
|---|---|
| 검정 지갑 / 회색 USB | 장면 후보 번호 각각 1 / 2, 확인 필요 |
| 빨간 지갑 | 후보 없음, 여전히 검사 결과이며 실제 분실물 부재 단정 안 함 |
| 빨간 우산 / 휴대폰처럼 생긴 물건 | 추가 확인, 매칭 엔진 미실행 |
| 꽃 스티커가 있는 지갑 | 번역 모델 미구성으로 보류, 스티커 조건을 버리지 않음 |
| VOVA 보조배터리 | 영문 특징 임베딩 미구성으로 보류 |

신규 시험 9개는 실제 팀 한국어 추출·브리지·정책을 사용한다. 상세 번역·임베딩 전달 시험만 명시적인 시험용 대체 객체를 사용하므로 실제 OPUS/MiniLM의 정확도나 시연 품질을 측정한 것이 아니다. 품목·색상 부정, 미지원·복수·모호한 품목, 스티커 범위 부정, 장면 불완전·Qwen 실패·잘못된 기하·NaN·중복 ID, 개인정보·길이, 모델 오류, 동시 실행 격리, HTTP 격리를 검증했다.

LF-5 전체 Python 710개 실행, 실패 0·환경 조건 11개 생략. 팀 PR #71~#74의 챗봇 통합·위젯·안내 주제·분석 에이전트 반영 후 결과다. 새 안내 주제로 이어 물을 때 주제 사전 누락으로 오류가 나는 경계도 보완했다.

작업 중 팀에서 이전 LF-5 PR #61을 통합했고, 11/5 역할은 변재원 챗봇 담당·정연우 보조로 조정됐다. 이번 변경은 기존 팀 구현을 보존하는 별도 초안 PR로 제출한다. 기존 위젯에 매칭 검사 UI를 중복 추가하지 않는다.

## 경계와 남은 작업

- 단일 장면 후보는 물품 DB의 실제 재고가 아니다. 장면 객체와 접수 ID의 연결·소유권·촬영 세션 계약이 필요하다.
- 결과에는 장면의 후보 번호만 포함한다. 원문·비공개 특징·실제 ID·좌표·파일 경로·일치 점수는 반환하지 않는다.
- 결과는 항상 `inspection_only=true`, `identity_verified=false`, `reservation_created=false`, `robot_authorized=false`다. 확인용 번호로 예약·반환할 수 없다.
- 공개 채팅 HTTP 경로와 현재 화면에는 연결하지 않았다. 사용자가 `report`를 채팅에 넣어도 검사 접근이 생기지 않으며 실제 DB 인증 잠금은 유지한다.
- 한국어 추출은 유한한 규칙이다. 사전에 없는 품목·복잡한 특징 문장을 모두 이해한다고 주장하지 않는다. 실제 번역·임베딩 평가와 사람 정답이 있는 독립 질의 평가가 필요하다.
- 검사 객체를 재사용할 때 번역기·임베딩 후보 버퍼가 섞이지 않도록 동시 요청은 대기 없이 busy로 돌려준다. 공통 계약·팀 매칭 코드·로봇 코드는 변경하지 않았다.

실서비스 연결 전에는 LF-4 인증·동의와 LF-6 후보/예약 계약, LF-20의 물품 ID·원본 특징 공급·모델 준비를 함께 확인해야 한다.
