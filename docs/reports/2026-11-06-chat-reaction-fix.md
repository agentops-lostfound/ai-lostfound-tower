# LF-5 짧은 반응과 검색 맥락 보완

사용자 제보인 `노란색 보조배터리 → 까비 ㅋ`에서 실망 반응을 새 인사로 분류하는 문제를 수정했다. 완결된 짧은 실망·수긍 표현을 구분하며 해당 반응 자체는 검색·조건 변경을 실행하지 않는다. 사용자 질문만 보유하므로 앞선 후보 유무를 임의로 단정하지 않는다.

- `까비 ㅋ`, `아쉽네 ㅠ`, `아깝다ㅋㅋ`, `쩝`, `에휴`와 수긍 표현 처리.
- 한글 자모가 NFKC 정규화되는 경우도 동일하게 인식.
- 반응 뒤 `그럼 흰색은?`은 앞서 말한 보조배터리를 유지한다. 중간에 다른 안내 주제로 전환했다면 이전 검색 대상을 되살리지 않는다.
- `아쉽네. 흰색 보조배터리 찾아줘`처럼 실제 요청을 포함한 문장은 짧은 반응으로 삼키지 않는다.
- 실제 모델 시뮬레이션 67/67 통과. 통합 Python 824건 실패 0·건너뜀 14, LF-5 819건 실패 0·건너뜀 13.
- 두 실제 서버 8111·8112에서 `노란색 보조배터리 → 까비 ㅋ → 그럼 흰색은?`을 재검증했다. 반응 때 검색 미실행, 후속 흰색 보조배터리 검색 성공과 실제 답변 일치를 확인했다.
