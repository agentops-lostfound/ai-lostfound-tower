## 4. 팀이 확인해 줘야 하는 것 — 안전 규칙이 바뀐 곳

#200 에서 아래 두 가지가 바뀌었고 이미 main 에 들어가 있다. 받아들이기 어렵다는 의견이 나오면 되돌린다.

1. **직원 대면 확인이 웹 확인 질문을 대신할 수 있다**(`staff_quiz_override`, `agents/service.py`)
   - 조건: 관리자 주소에서만 · 현장 관문 3개(신분증 일치·물건 특징·직원 최종 확인)가 모두 참 · 동의와 본인인증은 덮지 않음 · 저장된 확인 질문 결과는 고치지 않음 · 관제 메시지에 남김
   - 메인 AI 규칙(`agents/supervisor.py`)은 그대로이고, 이후 탑뷰·매칭·제출보관함 직원 교차 검증도 그대로
2. **잃어버린 역을 모르면 색 하나로 확인 질문이 통과한다**
   - 본센터에서 신분 번호 다시 입력 + 직원 교차 검증이 남는다

그리고 **실물 연결 설정을 켜면 [직원 확인 후 진행] 단추와 키오스크 회수가 진짜 로봇을 움직인다.** #202 에서 표시와 확인 창을 붙였다. 로봇 옆에 사람이 있고 정지 수단을 확인한 뒤에만 누른다.

## 7. 아직 정하지 않은 것

- **챗봇에서 모델(sLLM)을 쓰는 범위** — 지금은 coordinator·planner·researcher 와 intake 일부만 모델이고 supervisor·item_search·reporter 는 규칙이다. 접수 대화는 대부분 규칙이라 0ms 로 지나간다. 판단 칸 전부를 모델로 넓히면 한 턴이 10~20초로 늘 것으로 보인다(추정). 넓히려면 교육원에서 실제 모델 채점표로 확인해야 한다
- **장소를 확인 질문(채점)에서 빼고 후보 좁히기에만 쓸지** — 잃어버린 곳과 주운 곳은 다를 수 있다. 지금은 정직하게 다른 역을 답한 주인이 "모름"이라고 답한 사람보다 불리하다
- **팀 DB 에 남는 지난 가상 물건을 어떻게 정리할지**
