# 로컬 분실물 도우미 사용 안내

왼쪽 물건 설명에 품목·색·특징을 적고 분실 날짜·호선·역을 입력한 뒤 설명 정리하기를 누릅니다. 아래에 나타나는 내용을 확인하거나 수정할 수 있습니다.

설명 방법을 물건 사진으로 바꾸면 물건 하나가 보이는 사진을 올릴 수 있습니다. 사진에서 분실 날짜와 장소를 추측하지 않습니다.

녹음 파일 입력이나 채팅의 음성 질문 버튼으로 말한 내용을 글자로 바꿀 수 있습니다. 인식된 글을 확인한 뒤 직접 전송합니다. 마이크가 없으면 글로 입력하면 됩니다.

안내 채팅은 문서에 있는 절차를 근거와 함께 안내합니다. 물건 검색은 연결된 DB의 후보 조회이며 본인 물건 확정·접수·예약·반환 승인을 뜻하지 않습니다. 시연용 가상 DB 결과는 실제 습득물이 아닙니다.

설명을 확인한 뒤 이 설명으로 후보 검색 버튼을 누르면 확인한 품목·색상·분실 날짜·호선·역이 검색에 사용됩니다. 날짜를 넣으면 그 날짜 이후 접수부터 확인하고, 입력한 역을 먼저 찾아 결과가 없을 때만 같은 호선으로 넓힙니다. 채팅의 조건 지우기로 확인한 조건을 해제할 수 있습니다. 후보에는 후보 번호·품목·색상을 표시하며 실제 접수 번호·접수 역·일치 점수는 표시하지 않습니다. 실제 DB 검색은 서버가 본인인증·필수 동의를 확인할 연결이 준비되어야 사용할 수 있습니다.
