립밤·USB 세 번째·배송·보관함·고정재를 제외한 잠정 합계는 허브에 따라 **192,530원 / 199,440원**이다. USB 세 번째를 SK31 28,710원으로 추가하면 **221,240원 / 228,150원**, 30만원 잔액 **78,760원 / 71,850원**이다. 이는 구성 가정 계산이며 확정 견적이 아니다. 카드지갑을 2개로 하면 7,900원 추가된다.

## 주문 전 확인 및 누락

- 목업폰 링크 2개는 productId·itemId·vendorItemId가 동일하다. 다른 3색 선택을 확인한 것으로 볼 수 없다. 세 번째 옵션도 필요하다.
- USB 목표 3개이나 현재 2모델만 제시됐다. 각 수량·128GB 옵션 확정 필요. 같은 모델 2개를 사면 개체 구분 난도가 다르다.
- 카드지갑은 기존 목표 2개 대비 수량 미명시. 색상·수량 확인.
- 립밤은 2+2=4개, 핸드크림은 4종세트이므로 이전 목표 3개·2개보다 많다. 예비품으로 유지할지 결정.
- 보관 트레이 본체, 교체형 무광 바닥/레일, 반환 바구니, 로봇 베이스 고정, 카메라 어댑터·케이블 정리·보정 마커를 확인해야 한다. 구매하지 않고 보유품으로 충당하는 것도 가능하다.
- 홈캠 거치대는 실제 웹캠 결합, 설치 높이·수평 도달 거리·진동·처짐을 확인하기 전 탑뷰 장치로 확정하지 않는다.
- 허브 두 종류는 대안이며 둘 다 합산하지 않는다. 호스트 단자 A/C, 업스트림 대역폭·전원·포트 간격을 확인한다. USB 3.0 표기만으로 카메라·로봇 동시 안정성을 보장하지 않는다. 로봇 전원은 각 전용 공급을 유지하고 다중 카메라는 직접 포트/컨트롤러 분산도 검토한다.
- 접수 촬영 카메라와 중앙 탑뷰 카메라는 별도 위치다. 현재 icspring 1대 사용 인계만으로 동시 2개 촬영 지점이 충족됐다고 간주하지 않는다. 태블릿 카메라 대체도 화각·고정·앱 연동 시험 필요.
- 지갑 MVP용 실제 지갑과 맥세이프 카드지갑은 형태가 다르다. 일반 지갑 보유 여부 확인. SmolVLA 학습·집기 일반화는 미검증이다.
- 실제 보조배터리를 반복 낙하·압착하지 않도록 하고 반복 집기 시험에는 비활성 목업을 검토한다.

후속 조치: 미기재 가격·수량·색상 확정 → 보유 부품과 호환 확인 → 배송 포함 장바구니 견적 확정. 원본 링크는 사용자 대화 제공값이며 단축 링크 대상 옵션을 확인한 것으로 간주하지 않는다.
