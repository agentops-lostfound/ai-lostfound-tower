## 요구서 합계

| 구분 | 금액 |
| --- | ---: |
| 상품금액 합계: 수량 × 단가 | **255,180원** |
| 양식의 10% 가산분 | **25,518원** |
| 요구서 총액: 단가 × 1.1 × 수량 | **280,698원** |
| 300,000원 예산 대비 잔액 (요구서 총액 기준) | **19,302원** |

요구서의 L열은 `K열 × 1.1`, M열은 `L열 × J열`이다. 품목별 재계산 결과와 엑셀에 저장된 M5·M31 총액 280,698원이 일치한다. 10%는 양식의 가산 계산을 그대로 기록한 것이며 별도로 실제 세금·배송비를 확정한 것이 아니다.
