## 보관함 바닥 실험 제안

사용자는 집게 진입이 쉬운 올록볼록한 바닥을 제안했다. 돌기·리브는 물체 아래 공간을 만들 수 있으나 작은 물품의 굴러감·기울어짐·바닥 오집기 위험도 있어 확정 설계로 채택하지 않는다.

낮고 넓은 트레이의 교체형 바닥으로 평평한 무광 바닥, 낮은 평행 리브, 낮은 둥근 돌기를 비교한다. 높이·간격은 집게 두께·개방 폭·최소 물품 크기를 실측한 후 정한다. 로봇 도달 범위·트레이 벽 간섭을 확인하고 물품별 성공·실패를 기록한다. 최종 바닥은 SmolVLA 학습·평가 조건과 일치시킨다. 실제 성공률은 미검증이다.

## 포토박스 선정 기준

첫 구매 검토 항목이다. 접수 촬영용과 중앙 로봇 작업 공간은 구분한다. 일반 포토박스 안에서 로봇 집기가 가능하다고 가정하지 않는다.

- 40cm급부터 비교하되 내부 유효 공간·최대 물품·촬영 거리·카메라 화각을 확인한다. 크기는 미확정이다.
- 상단 촬영구와 카메라 별도 고정 공간을 확인한다.
- LED 밝기 조절·확산판/확산천·무광 배경 교체 여부를 확인한다.
- 반사 물품의 핫스폿·색 재현·실제 카메라 노출에서의 LED 깜빡임을 시험한다.
- 전원 공급 장치·배경판·배송을 포함한 가격을 비교한다.

쿠팡·네이버쇼핑 직접 조회가 각각 HTTP 403·418로 차단되어 검증된 제품 후보·판매가·재고를 확보하지 못했다. 특정 제품 추천이나 구매를 완료한 상태는 아니다.

### 접근 제한 진단

클라우드 환경은 connected, 인터넷 정책 unrestricted/enforced이며 일반 HTTPS 비교 요청은 200이었다. 같은 기존 프록시 경로에서 쿠팡은 CDN(edgesuite)의 Access Denied, 네이버는 비정상 접근 감지에 따른 네트워크 일시 제한 안내를 반환했다. 네이버 안내의 가능한 사유는 과도한 요청 IP·VPN·확장 프로그램 등이며 어느 항목이 해당하는지는 확정하지 못했다. 단순 환경 도메인 허용 설정 누락보다는 쇼핑 서비스 측 접근 제한을 가리키는 증거다. 공유 출구 IP와 비브라우저 요청의 영향은 미확정이다.

현재 도구에는 사용자 Windows PC/Chrome 조작 기능이 없다. 클라우드 요청 실패를 사용자 PC의 프록시 고장으로 해석하지 않으며 PC 설정·쿠키·보안 옵션은 변경하지 않았다. 쇼핑몰 접근 통제를 우회하지 않는다. 허용된 로컬 브라우저 접근 또는 공식 상품 API 등 별도 접근 경로가 확보되어야 상품 조회를 재개할 수 있다. 네이버 오류 페이지는 공식 원클릭 진단 및 고객센터 문의를 안내한다. 현재 구매 조사 차단은 미해결 상태다.
