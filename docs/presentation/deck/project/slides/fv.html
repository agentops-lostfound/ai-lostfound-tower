순필 님이 만든 확장 실험입니다. 오늘 본 시연은 칸 8개의 자세를 미리 가르친 방식이고, Field Vision은 그것을 대체한 것이 아니라 따로 실험한 것입니다. 한 줄 설명: 탑뷰 카메라가 찾은 물건 위치로 로봇이 접근 자세를 계산하고, 손목 카메라로 보정해 집은 뒤 저장해 둔 반환대 위치로 옮깁니다. 로봇 동작을 학습시킨 방식(VLA)이 아니라 역기구학 계산 + 영상 보정입니다. 원점과 반환대 자세는 저장해 둔 값을 씁니다. 0.928은 검증 사진에서 잰 검출 모델 지표이고, 집기 성공률이 아닙니다. 품목마다 확인된 범위가 달라 성공률 숫자는 발표하지 않습니다. 관제탑에 붙이려면 물건 번호 연결 · 운영 4품목 · 작업 응답 약속을 맞추는 작업이 더 필요합니다. 영상과 화면 캡처는 아직 받지 못해 넣지 않았습니다.
