왼쪽은 물건을 맡기는 역 키오스크와 분실인 휴대폰, 가운데는 모든 연결이 지나가는 관제탑 PC, 오른쪽은 부산역 본센터입니다. 보관함은 4줄 × 2칸이고, R은 보관함 줄(Row) 번호입니다. 줄마다 품목 하나(R1 휴대폰 · R2 보조배터리 · R3 핸드크림 · R4 립밤), -1은 먼 칸, -2는 로봇 쪽 칸입니다. 그래서 R4-1은 '립밤 줄의 먼 칸'입니다. 로봇팔은 칸 번호에 맞춰 미리 가르친 자세로 집어 제출보관함에 놓습니다.
