3 · 분실물 관리 (로봇암) · KAN-31

보관하고, 승인된 물품만 내줍니다

업무하는 일우선순위
보관 동작접수된 물건을 할당된 칸에 넣기필수
반환 동작승인된 물품을 꺼내 수령 위치에 놓기필수
반환 안전 규칙번호 일치 확인, 상태는 정해진 순서로만 이동필수
집기 학습학습으로 집기 시도, 실패하면 저장 동작으로 대체도전

로봇은 SO-101 로봇팔을 사용하고, 저장된 동작을 재생하는 방식으로 시작합니다.

반환 안전 규칙

  • 승인 번호와 물품 번호가 같을 때만 진행
  • 검증과 예약을 한 번에 처리(원자적 예약)
  • 상태는 한 방향으로만 이동
  • 실패·재시작 시 ERROR_HOLD로 멈추고 자동 재시도 없음
  • 보안 시험 10개 범주 (아직 실행 전)

주담당(안) 이순필 · 상태 변경 SQL은 정연우 협업 · 반환 안전 부담당은 변재원
