근거

VLM은 사진과 글을 함께 읽는 언어 모델입니다. 3번은 Qwen이 다시 보는 것이 아닙니다. 모델이 아닌 일반 계산 코드가 같은 사진에서 회색 펠트를 기준으로 색을 숫자로 재고, 물건의 길이 · 폭을 재서 Qwen 답(색 · 품목)과 맞는지 확인합니다. 다르고 측정이 확실할 때만 고칩니다(예: 핸드크림 ↔ 립밤은 길이로 구분). 오른쪽은 통합 화면의 실제 사진 분석 카드로, 빨간 립밤을 Qwen이 '분홍'으로 읽었지만 색 측정으로 '빨강'으로 고쳐 저장한 예입니다. 글자·스티커 같은 비공개 특징은 값을 가리고 저장됐다고만 보여 줍니다.
