## 4. 고치는 방법
- 간단한 글자 수정: 덱 편집기에서 직접 고치면 됨
- 움직이는 그림(`x-embed`)·여러 장 수정: `src/` 파이썬으로 다시 만든다
  - `python src/build.py 출력폴더` → 모든 슬라이드 HTML 생성(그림은 embeds*.py, 로봇팔은 arm.py)
  - **주의**: build.py 출력에는 편집기에서 직접 고친 내용(v7 위치, proof 등)이 없다. 바뀐 장만 골라 `deck/project/slides/`에 복사해서 발행할 것
  - x-embed 규칙: 슬라이드당 8개 이하, 하나당 16KB 이하, CSS 애니메이션만
- 검사: `node src/anim.js 슬라이드폴더 출력 '[["system",[1,3,5]]]'`(시간대별 캡처), `node src/animw.js`(Windows 글꼴 흉내), `node src/clip.js 슬라이드폴더`(그림 밖으로 나가는 요소, `../deck.json` 필요) — Playwright 필요
- 영상: `src/make_clips.py`(구간 자르기·실물/가상 나란히·가상 영상 구간 배속 `warp`), `src/mosaic.py`(입력칸 모자이크). 원본 영상은 저장소에 없음(용량) — 재원에게 받기

## 5. 덱 문장 규칙
- 화면 문장은 "~한다"체 금지(명사형·제목형). 표지·마무리의 "~습니다"는 그대로 두기로 함
- 발표 화면에 이름·전화번호·신분 번호·비밀값 금지. "중간발표", 참고 앱 이름 쓰지 않기
- 핸드크림: 하늘색 튜브 + 남색 T자 뚜껑(아래). 립밤: 바세린, 위 빨강·아래 흰색 직각
- 4쪽 로봇팔: 비스듬히 위에서 본 SO-101(관절 계산으로 굽힘) + 옆모습 카드. 팔 길이 비율은 추정(위팔 84 : 아래팔 108 : 손목~집게 56) — 실제 링크 길이 알면 arm.py 수정

### 7-3. 개인정보 가리는 방법 (20쪽에 쓴 방식)
