# 비전 검출 현황 — 2026-11-03 (LF-3)

## 현재 결론

사진 → YOLO 검출 → 물체별 crop·중심 픽셀 → Qwen 특징 추출 → 통합 JSON 저장의 연결은 실제 로컬 실행으로 확인했다. 다만 테스트한 여러 물품 사진에서 USB·립밤이 미검출돼, 전체 대상 물품에 대한 안정적 검출 성능은 아직 확보하지 못했다.

이 문서는 개발 PC의 실행 JSON·로그·박스 표시 이미지를 확인한 관찰 기록이다. 소수 사진에서의 결과이며 정량 성능 평가가 아니다. 실사진과 결과 파일은 저장소에 포함하지 않으므로 저장소만으로 아래 관찰을 재현할 수는 없다.

## 구성과 역할

```text
사진
├─ YOLO26n → bbox → crop·중심 픽셀
└─ ArUco → 실측 대응점 homography → 작업대 mm 좌표
                         ↓
crop + 좌표 → Qwen 특징 JSON → 물체 ID에 연결한 통합 JSON
```

- YOLO: Ultralytics YOLO26n COCO 사전학습 가중치. 우리 물품으로 추가 학습하지 않았다.
- 최근 기준: imgsz=640, confidence=0.25, 로컬 시험 장치=CPU. 설정 파일의 device=auto이며 CLI에서 cpu를 지정했다.
- YOLO 클래스명은 원래 COCO 결과를 유지한다. 품목명이 틀려도 물체별 bbox와 crop 품질은 별도로 평가한다.
- Qwen: Qwen3-VL-2B-Instruct, NF4 4-bit, RTX 3050 6GB에서 실행. 일반 물품용 general_items_v1 프롬프트·검증을 사용한다.
- Qwen에는 YOLO 품목명을 주입하지 않고 crop만 전달한다. 결과를 통해 품목·색상·형태·문자·스티커 등 특징을 기록한다.
- ArUco 실측 좌표 미입력. 최근 시험 사진에서 마커도 검출되지 않아 실제 mm 좌표는 null이다.
- 사용자 설명과의 매칭·후보 선정·로봇 제어는 이 시퀀스에 아직 연결하지 않았다.

## Qwen 연결과 남은 오류

- 일반 물품용 스마트폰 2개 실행에서 전체 약 51.5초, 특징 JSON 2개 저장을 확인했다.
- 저장소 내 Qwen 소스 복사본과 기존 CUDA 환경·캐시로도 전체 약 49.7초에 2개 처리를 완료했다.
- lib.jpg를 YOLO 없이 Qwen에 직접 입력했을 때 lip_balm으로 분류했다. 생성·검증 약 12.2초, 추출 함수 전체 약 28.9초였다.
- 해당 립밤 사진의 NIVEA 문자를 AVENZA로 오독했고 인쇄 부분을 스티커로 판단했다. 재질·문자·스티커 등의 시각적 정확도는 추가 평가가 필요하다.
- status=ok/complete는 실행·형식 검증 성공이다. 의미적 정답이나 실제 물품 식별 정확도를 보증하지 않는다.
- YOLO가 놓친 물품은 crop이 없어 Qwen에도 전달되지 않는다. YOLO 미검출과 Qwen 인식 오류는 분리해서 개선한다.
- 현재 Qwen 프로세스를 실행마다 시작하고 모델을 로딩하며 crop은 순차 처리한다. 상시 worker·출력 길이 등 지연 개선은 별도 검토 대상이다.

## 다음 작업

1. 현재 모델·기준 설정을 비교 기준으로 유지한다.
2. 단독·복수 배치·빈 작업대 사진에 정답 박스를 달아 평가 세트를 고정한다.
3. 폰·USB·립밤·핸드크림·지갑·보조배터리의 학습 사진을 확보한다. 공개 데이터는 실제 탑뷰 사진을 보완하는 용도로 검토한다.
4. 각 대상 물체를 별도 박스로 표시하고 모두 0:item으로 학습한다. 손·배경 등 다른 클래스는 무조건 item으로 합치지 않는다.
5. 촬영 세션과 유사 이미지가 학습·검증·테스트에 섞이지 않도록 분리한다.
6. YOLO26n 시험 학습 후 물품별 미검출·오검출·중복 박스·crop 품질·시간을 비교한다. 필요하면 동일 조건에서 입력 크기와 26s를 비교한다.
7. 검출 안정화 후 Qwen 특징 정확도·지연과 ArUco 실측 오차를 각각 검증한다.

item 학습 설정·스크립트는 준비됐으나 공개 데이터 다운로드·통합·실제 학습은 완료되지 않았다. 학습용 item 한 클래스와 Qwen의 세부 품목 분류는 역할이 다르다. 기존 팀 4종 클래스 순서는 변경하지 않았다.
