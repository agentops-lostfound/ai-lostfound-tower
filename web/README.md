## 습득자 등록 화면

- `found-item-intake.html`: 습득물 사진 촬영·업로드, 물건 종류, 발견 장소, 상세 설명, 습득자 이름·연락처 입력 및 접수 번호 발급을 제공하는 반응형 프런트엔드 시제품입니다.
- 브라우저에서 접수 정보를 JSON으로 내보낼 수 있으며, JSON에는 연락처와 사진 데이터가 포함됩니다.
- 현재는 서버/DB 저장이나 담당자 전송 기능이 없습니다. 실제 운영 전 백엔드 API, 안전한 사진 저장소, 접근 제어 및 개인정보 처리·보관 정책을 연결해야 합니다.
