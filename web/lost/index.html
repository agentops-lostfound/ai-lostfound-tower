잃어버린 물건 찾기

해운대역·서면역·부산역에서 잃어버린 물건을 신고하세요. 맞는 습득물이 있으면 찾기 번호를 드리고,
부산역 본센터 키오스크에서 본인 확인 후 로봇이 물건을 꺼내 드려요.

  1. 1. 분실 신고
  2. 2. 확인 질문
  3. 3. 찾기 번호
  4. 4. 본센터 방문

무엇을 잃어버리셨나요?

아는 만큼만 고르세요. 모르는 칸은 비워 두면 됩니다.

물건 종류 *
색상 (가장 넓게 보이는 색 하나)

적은 특징은 본인 확인 질문에도 쓰여요. 이름·전화번호 같은 개인정보는 적지 마세요.

본인 확인 (시연용 가상 신분증 기준)

이름과 번호는 이 화면에서 가려서(예: 홍*동, ******-3******) 보냅니다. 본센터 키오스크에서 같은 값을 다시 입력해야 물건을 받을 수 있어요.

확인 질문

비슷한 습득물이 있어요. 본인 물건인지 확인하려고 하나만 더 여쭤볼게요.

부산역 본센터에서 받는 방법
  1. 부산역 본센터 키오스크에서 「물건 찾으러 왔어요(회수)」를 누릅니다
  2. 찾기 번호 - 를 입력합니다
  3. 가린 신분 번호 - 를 입력합니다
  4. 로봇이 보관함에서 꺼내 제출보관함에 두면, 직원이 신분증·물건을 확인하고 건네 드려요
진행 상황

    교육용 시연 화면입니다. 실제 운영에서는 본인 확인·개인정보 처리방침·보관 기간 정책이 따로 필요합니다. 현금·신분증·위험물은 역무실로 문의하세요.
