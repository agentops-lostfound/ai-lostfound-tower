# 보관함 기준 치수

- 사용자 확인: 가로 46.88cm, 세로 20.2cm.
- 적용값: 가로 468.8mm, 세로 202mm.
- 기준: 좌상 ID 0 중심→우상 ID 1 중심(가로), 좌상 ID 0 중심→좌하 ID 3 중심(세로).
- 실제 ArUco 좌표 설정에 저장·재조회 확인 완료.
- 보관함 평면 좌표용 치수이며 로봇 베이스와의 위치·방향 보정은 별도 필요.

## 로봇 기준 실측 배치

- 전방 거리 약 7.9cm = 79mm: 맨 아래 회전축 중심에서 가까운 ID 3–2 마커 중심선까지.
- 좌우 어긋남 0mm (사용자 확인).
- 책상 표면에서 마커 표면까지 높이 15mm.
- 보관함은 로봇 정면과 평행한 수평 배치로 가정. +X 전방, +Y 로봇에서 보관함을 바라볼 때 왼쪽, +Z 위.
- 계산해 저장한 기준점(mm): ID0=(281,234.4,15), ID1=(281,-234.4,15), ID3=(79,234.4,15).
- 보관함 중앙 예상=(180,0,15)mm. 접근 높이 80mm를 더하면 (180,0,95)mm; 계산용이며 실제 이동 검증값 아님.
- 위 3점은 독립 실측 3점이 아니라 사용자 제공 배치 치수와 평행 가정으로 유도한 값. 잔차 0은 물리 정확도 보장이 아님.
- 실제 URDF 베이스축/관절각/TCP 정합과 이동 경로 검증은 아직 필요.
