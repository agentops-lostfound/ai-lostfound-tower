# 분실물 검색·반환 로봇 개발 일지

2026-11-10 · 한국 표준시(KST). 실행 시각이 확인되는 단계에는 시간을 적고, 나머지는 실제 작업 순서로 정리했다.

**목표**는 한 번에 한 물건을 접수하고 사진·특징·시간·장소를 저장한 뒤, 분실자가 입력한 정보로 보관함에서 해당 물건을 찾아 로봇이 반환대에 놓는 것이다. 현재 베타는 등록된 물품 검색부터 집고 들어 올리는 단계까지 다룬다. **핸드크림을 실제로 집은 사례는 사용자가 확인했다.** 그 성공은 특정 실행 ID와 연결되지 않았으며, 이후 변경한 우측 보정과 최신 하강 조건까지 검증한 결과는 아니다.

## 3. 집기 시퀀스에서 발견한 문제와 변경 순서

1. **첫 집기 시도.** 영상만으로 들었다고 판단했지만 사용자가 실패를 확인했다. 집게가 벌어진 채였거나 튜브를 충분히 잡지 못한 사례가 있었다. 이후 실물 성공과 영상 접촉 후보를 별도 기록했다.
2. **준비자세와 개방 순서.** 처음에는 HOME에서 집게를 열거나 이전 개방량을 유지했다. 저장된 닫힌 준비자세로 복귀한 뒤 새로 검출하고, 물건 위에 도착해서 여는 순서로 수정했다. 안정화 과정에서 모델 작업 완료 상태 재조회, 마커 누락 시 새 프레임 재확인도 추가했다.
3. **하강·상승 높이.** 튜브보다 높게 잡는 문제 때문에 집기 기본 높이를 마커면 위 15mm에서 5mm로 낮췄다. 집은 후에는 하강 전 접근 높이까지 올라가 사용자 확인 때까지 유지한다.
4. **접촉과 추가 닫기.** 튜브가 말랑해 시간만 늘리거나 부하만으로 성공을 판단할 수 없었다. 하강한 뒤 양쪽 손가락과 튜브 간격을 보며 닫는다. 영상 접촉이 불확실해도 진행하는 시험 모드는 별도로 기록한다. 한 실행에서는 추가 닫기 3초 동안 1614→1612틱만 움직였다. 명령과 실제 위치 차이를 8틱으로 제한한 영향이 있어 추가 닫기 단계만 시간·토크 상한 방식으로 변경했다. 토크 제한 200, 최대 3초와 정체 보호를 시험한 뒤 사용자가 실물 집기 성공을 확인했다. 이후 너무 세다는 피드백으로 **현재 추가 닫기는 최대 1.5초**다. 이때는 2초 정체 판정보다 시간 제한이 먼저 끝난다.
5. **속도와 도착 판정.** 모든 자세를 3초로 이동시켰을 때 손목이 명령을 따라가지 못해 정지했다. 큰 이동(관절 한 축이라도 45° 초과)은 5초, 작은 이동은 3초로 나눴다. 이동 중 추종 오차 90틱, 도착 오차 46틱, 도착 대기 5초를 적용했다. 실제 목표 도달과 시간초과를 구분한다.
6. **두 물건 중 목표 선택.** 프로토타입에서 사진·설명을 입력해 대상 검색을 완료한 뒤 시작하도록 연결했다. 검색 중 시작 버튼은 비활성화한다. 선택한 색상이 손목 카메라까지 전달되지 않아 하늘색에 분홍색 필터가 적용되던 문제를 수정했다.
7. **오른쪽 접근 경로.** 손목 목표 3301틱이 저장 상한 3286틱을 넘어 정지했다. 실측 관절 범위를 자세 계산에 반영했다. 시험용 중앙 자세 강제 경유와 이동 중 손목값 고정을 제거하고, 현재 관절값에서 집게 끝 위치·방향을 계산한다. 목표 위치, 아래를 향하는 각도, 물품의 짧은 축에 맞춘 벌림 방향을 함께 검사한다.
8. **회전과 개방.** 우측 물품 위에는 도착했지만 집게가 물건과 평행한 사례가 있었다. 저장 영상에서 약 83°의 정렬 차이를 확인해 모델의 벌림 축을 경험적으로 교정했다. 도착 후 ARM 영상에서 회전 필요성을 판단하고, 필요하면 높은 위치에서 보정한 뒤 다시 확인한다. 모델 축 교정의 정확도는 자세에 따라 추가 검증이 필요하다.
9. **탑뷰와 ARM 외형 실패 구분.** 탑뷰에서는 작은 검출 박스 가장자리까지 색상 마스크가 확장돼 외형이 거절됐다. 잘린 이미지에 여백을 넣어 처리했다. ARM에서는 옅은 파란색과 받침이 함께 잡혀 방향이 흔들렸다. 근접 영상의 색상·잡음 필터와 새 프레임 재시도를 추가했다. 저장 영상과 실시간 샘플에서 각각 검출을 확인했다.
10. **우측 20mm 실측 보정.** 한쪽 손가락이 물품 중앙에 놓이는 오차를 사용자가 확인했다. 전역 원점 대신 해당 우측 지점 주변 30mm와 유사 손목 자세에만 보정을 적용했다. 뒤늦게 옆으로 이동하던 방식을 고쳐 처음부터 보정된 목표로 계획한다. 이 위치는 마커면 위 접근 높이 45mm에서 접근·집기·상승 자세 계산을 통과했고 55mm에서는 통과하지 못했다. 이는 해당 자세의 모델 계산 결과다.
11. **하강 전 검사 회귀.** 물건을 찍지 않게 하려다 개방 후 양쪽 손가락이 화면에 보여야 하강하는 조건을 넣었다. 50% 개방하면 오른쪽 손가락이 화각 밖으로 나가는 장비여서 정상 동작도 차단됐다. 41→45→50% 단계 검사도 같은 문제가 있어 제거했다. 현재는 50%로 한 번 열고 보이는 손가락의 겹침을 확인한다. 양쪽 접촉 확인은 하강 후 닫기 단계에서 수행한다.
12. **최신 간격 판정.** 손가락 전체를 감싼 사각형의 빈 모서리가 충돌로 처리되는 문제를 수정했다. 실제 손가락 윤곽과 물품을 감싼 외곽의 최단 거리를 측정한다. 640px 영상에서 임시 기준은 4px 이상, 연속 두 프레임이다. 이전 저장 영상은 25.7px로 통과했고, 최근 정지 후 촬영한 영상은 0px로 차단됐다. 이는 영상 거리이며 실제 접촉력이나 mm 거리 측정값은 아니다.

## 현재 이어서 할 작업

**현재 실물 시험의 기준 순서**는 목표 검색 → 닫힌 HOME에서 새 탑뷰 검출 → 보정된 물품 위로 접근 → ARM 방향 확인·필요 시 회전 → 50% 개방 → 가시 손가락 간격 확인 → 하강·닫기 → 토크 제한 200으로 최대 1.5초 추가 닫기 → 접근 높이로 상승·유지다.

다음 실물 시험에서는 우측 하늘색 물품의 개방 후 간격과 실제 손가락 위치를 함께 대조해야 한다. 최신 0px 장면은 하강 금지 상태다. 두 물건 중 선택부터 최신 보정으로 집고 상승하기까지의 연속 성공은 아직 확인되지 않았다. 고정 반환대 이동·방출, 학습 기반 손목 집기, 시간·장소를 포함한 팀 접수 웹 연동은 이후 단계다.
