## 7. 현재 상태 (Codex·팀 인계용, 11-12 15:10경)

**실행과 규칙**
- 실행: `Start-Beta.cmd` → `.venv\Scripts\python.exe -m uvicorn beta.server:app --port 8871`. 파이썬은 반드시 `.venv`를 쓴다(시스템 파이썬에는 cv2가 없다).
- 수정할 때마다 버전을 올린다. 올릴 곳은 `beta/version.py`, `beta/static/beta.html`(buildVersion, `?v=`), `beta/static/beta.js`(UI_VERSION/UI_BUILD, label.title 맨 앞 변경 메모) 세 군데다. 수정 전에 `.omc/snapshots/`에 스냅샷을 남기고, 진행 기록 끝에 한 줄을 추가한다.
- `beta.js`는 CRLF다. 수정한 뒤 `node --check beta/static/beta.js`로 검사한다.
- 서버 재시작은 로봇 시퀀스가 멈춰 있고 데이터 수집이 꺼져 있을 때 한다. 순서: `/api/manual/disconnect` → Start-Beta cmd 종료 → 재시작 → `/api/health` 확인 → `/api/manual/connect`(토크는 바꾸지 않음). **연결을 끊어도 켜져 있던 토크는 유지돼 팔이 제자리에 있다**(`manual_worker.py` 종료 처리). 그래서 HOME이 아니어도 멈춰 있으면 재시작할 수 있다(11-12 실측: 재시작 전후 관절값 동일).
- 테스트는 모듈별로 돌린다(`python -m unittest beta.test_xxx`). `test_robot_actions`와 `test_grasp_flow`는 원래부터 고장이라 제외한다. 나머지는 v0.2.77 기준 모두 통과한다.
- 사용자에게 보이는 글(답변, 진행 메시지, 권한 확인 설명, 선택지)은 모두 한국어로 쓴다.
- 물품별 땜질은 하지 않는다. 품목 이름이 아니라 측정값(탑뷰 실제 폭 `physical_size_mm`, `WIDE_FLAT_MM`=60, 잘림, 고정 손가락 쪽)으로 규칙을 만들고, 다른 물품의 과거 집기 기록으로 재생해 회귀를 확인한다.

**운영 설정 (`beta_data/workflow.json`)**
- 접근 45mm, 집기 5mm, 간격 범위 6~56px(실제 하한은 손가락 등록·학습 기울기로 집기마다 다시 계산, 예: 폰 16.4px, USB 28.9px), 보정 한도 20mm, 사전 오프셋 k 0.35 / c 4mm / 상한 30mm.
- 종료 방식은 놓기(return)이고 놓기 자세는 저장돼 있다. 이송 높이 120mm, 추가 닫기 2.0초, 위치 보정 기록 모드는 꺼짐, 자동 접수 꺼짐.
- **return_on_unconfirmed는 지금 false다**(오전 true에서 사용자가 바꿈). 그래서 들어 올림 판정이 "미확정"이면 놓기로 가지 않고 그 자리를 유지한다.

**학습·보정 값**
- 하강 간격 감소량 8.9px(`descent_gap_shift.json`, 매 집기마다 갱신), 영상 간격 기울기 6.41px/mm(`visual_gap_slope.json`). 보관함 평면 보정 켜짐. 개방 실측 50/80/100% = 82/120/135mm.
- YOLO: `models/detector/best.pt` + `meta.json`. `trained_classes`에 6품목이 모두 있어 탑뷰 단독 판정이 켜져 있다(11-12 13:20 적용, 16/40에폭 중단, 12에폭 가중치, val mAP50-95 0.928). 이전 USB 전용 모델은 `best-usb-only-20261112.pt`.

**집기 흐름 (v0.2.77)**
- 검색(품목 단어 범위 제한, 이름·메모 가점) → 탑뷰 좌표·방향·사전 오프셋 → 접근(10° 이하 이동은 짧게) → ARM 검출 박스 추적 시작 → 방향 확인·회전 → 개방(폭 60mm 이상은 80% 이상) → 고정 손가락 간격 보정 → 하강 중 2회 간격 점검 → 하강 → (폭 60mm 이상) 바닥까지 하강 → 바닥 간격 확인 → **(폭 60mm 이상) 옆면 밀착** → 영상을 보며 닫기 → 토크 200 추가 닫기 → 들어 올림 판정(특징점 + 외곽 유지) → 놓기 이송 또는 위치 유지.
- ARM 경계: 검출 박스 안 → 외관 색 마스크 → (작은 조각이면) 감싸는 비초록 몸체 → 초록 배경 GrabCut 완성 → 고정 손가락 쪽 긴 경계. 박스를 못 얻으면 예전 방식으로 동작한다.

**하드웨어 사실 (모든 수정에서 확인할 것)**
- 고정 손가락이 하나뿐인 집게다. wrist_roll 부호는 +1이다. shoulder_lift는 뻗은 자세에서 수십 틱 처진다.
- 1틱은 특정 자세에서 약 0.4mm다(작업공간 전체의 고정 환산값 아님). 손목 굽힘 기계 한계는 3288틱이다.
