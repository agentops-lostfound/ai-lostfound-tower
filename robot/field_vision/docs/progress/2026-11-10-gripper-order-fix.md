# 준비자세에서 먼저 집게를 열던 순서 수정

- 사용자 지적에 따라 접근 목표의 집게 값은 시작 개폐 위치를 유지한다.
- 물건 위 접근 완료 응답을 받은 후, 그 순간의 실제 팔 관절값을 유지하며 집게만 50% 연다. 준비자세의 오래된 관절값으로 되돌아가지 않는다.
- 이후 하강 → 영상 접촉 후보 닫기 → 확인 들기로 진행한다. 접근이 실패하면 열기/하강은 실행하지 않는다.
- 화면 순서 안내도 동일하게 수정했다. HOME 값은 변경하지 않았다.
- 함께 발견한 연결 오류 수정: 분석 요청의 초기 복사본을 대기하지 않고 실제 작업 ID의 최신 상태를 읽는다. 모델 로딩 중 정지한 분석 대기에서는 순간 피드백 지연을 허용하되 이동 전 0.8초 이내 최신 관절 피드백을 다시 요구한다.
- 준비→접근의 큰 관절 변화는 한 구간 제한을 넘지 않도록 분할한다. 충돌 회피/정밀 도달 보장은 아니다.
- 코드 수정 당시 이미 시작한 66개 검사는 통과했다. 이후 사용자 요청에 따라 추가 시뮬레이션을 하지 않았다. 수정본 서버 적용 후 실제 동작 검증은 사용자와 다음 시험에서 진행한다.
- 사용자 작업 방침: 요청한 수정 후 불필요한 별도 시뮬레이션 반복 없이 실제 장비 시험으로 검증한다. 실제 동작/성공 여부를 확인하지 않은 채 완료로 보고하지 않는다.
