# 임시 보정 v1 · 실제 관절값의 모델 재현

- 사용자 방향 확인과 수동 기록 3개를 사용했다. 중앙 높이는 판 위 약 65mm, 책상 기준 약 80mm로 정정했다.
- 중앙 위치 (180,0,80)mm 및 집게 축 수직 아래 가정으로 모델 자세를 풀고 raw encoder 기준점을 대응시켰다. 이 모델 역해가 실제 중앙 관절각의 유일한 정답이라는 뜻은 아니다.
- raw tick 변화는 4096 ticks/회전으로 환산하며 normalized를 각도로 사용하지 않는다.
- 1~4번 부호 + 가설은 추가 2개 자세에서 방향/이동량과 대체로 맞았다. 5번은 변화가 없으므로 기준 모델값에 고정하고 기준 raw에서 5 ticks 이상 달라지면 재현을 거부한다.
- 중앙은 영점 계산에 사용한 값이므로 비교 정확도에 포함하지 않는다. 추가 비교 자세는 목표 대비 약 5.8mm, 5.2mm 차이가 났으며 높이/위치가 대략 측정이라 실제 정확도 평가로 단정하지 않는다.
- 읽기 전용 화면: /static/reproduction.html. 현재 관절 raw 피드백을 모델 측면·탑뷰 그림에 반영하고 저장된 3개 자세와 사진도 비교한다.
- 현재 수동 제어 연결을 유지했다. 서버 재시작/토크 변경/이동 명령을 하지 않았다.
- 후보: beta_data/provisional_reproduction.json. 원본 관절 및 사진은 기존 manual_sessions에 보존. 하드웨어 자동 이동 허용값은 false이며 검증된 서보 이동용 보정으로 취급하지 않는다.
- 사용자 방침: 초기 구동을 우선하고 실제 작업의 목표/실측 오차를 기록해 보정을 반복 개선한다. 기본 축/방향/범위와 미세 위치 오차를 구분한다. 이후 보정 갱신 시 이전 버전과 비교자료를 보존한다.
- 검증: 46개 unittest 통과, Python/브라우저 JS FK가 세 자세에서 1e-6mm 이내로 일치. 페이지·스크립트·설정 파일 HTTP 200 및 실제 라이브 피드백을 이용한 모델 계산 확인. 브라우저 렌더링/실물 자동 이동은 별도 검증 전.
