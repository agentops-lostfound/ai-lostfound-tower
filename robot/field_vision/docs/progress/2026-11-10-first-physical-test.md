# 에이전트의 첫 실제 1번 왕복 제어

- 사용자 승인: 실제 팔 테스트 진행 요청. 현재 자세에서 맨 아래 1번만 약 +5도 회전 후 원위치 복귀로 범위를 한정하여 시행했다.
- 수동 GUI의 기존 단일 직렬 소유자를 사용했다. 새 직렬 연결이나 자동 재보정 없음.
- 시작 1번 raw=2006. 도착 raw=2062, 엔코더 변화 약 +4.92도.
- 1번만 조그 명령을 보냈고, 다른 켜진 관절은 기존 위치 유지. 토크 ON/OFF 변경 명령 없음.
- 정지 해제 ACK 직후에는 상태 캐시가 이전 잠금을 유지해 첫 시도가 이동 전에 중단됐다. 새 피드백 갱신을 기다린 뒤 재시도했다.
- 도착 후 사진 저장 시 상태 캐시에 이동 중 정보가 남아 저장이 거부됐다. 실제 1번은 도착·정지한 상태였으며 이를 확인하고 복귀했다. 복귀 후 자세·두 카메라는 저장됐다.
- 도착 즉시 읽기보다 정착 후 피드백을 기준으로 복귀 오차를 평가해야 한다. 상세 수치와 전체 표본은 work/physical_pan_5deg_test.json의 settled_samples 및 settled_delta_ticks 참조.
- 이후 피드백에서 1번 약 -0.6도 및 팔꿈치 약 0.9도 변화가 관측됐다. 다른 축에 조그를 보내지 않았더라도 하중/관절 유지/정지 시점 차이에 따른 오차를 점검해야 한다. 정확한 원인을 단정하지 않는다.
- 현재 API halt는 켜진 관절을 그 순간 읽은 위치로 유지하므로 목표점 유지 명령과 다르다. 차후 다축 목표 이동에서는 목표 명령/감속/도착 확인을 분리해야 한다.
- 실제 카메라로 복귀 자세를 확인했지만 집게의 mm 이동량은 실측하지 않았다. 모델 좌표 정확도 검증이 아닌 실제 통신·회전·복귀 시험이다.
- 자동 집기/전체 팔 목표 좌표 이동은 아직 시행하지 않았다.
