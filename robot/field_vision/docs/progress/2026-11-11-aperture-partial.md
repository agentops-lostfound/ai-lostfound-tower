# 큰 물건 개방 폭·부분 경계 처리 — v0.2.7 / 20261111.07

## 사용자 요구와 적용 범위
- 손목 부호/SIGN, TCP 프로필, 정지·추종보정 로직 및 기존 고정손가락 px/mm/오프셋 학습 파일은 변경하지 않음.
- 개방률 종속 정보는 개방폭 실측표, 반대손가락 여유/영상제외 문맥에 한정. 오프셋 관측에는 개방률/실측표revision을 기록만 추가하고 학습을 분리·무효화하지 않음.

## 개방 폭 측정/선택
- 설정 → 집게 개방 폭. 40/50/60/70/80/100%별 실측 안쪽 최소 폭을 입력. 빈칸은 미측정.
- 기준은 마커 평면 위 실제 접촉 높이(기본5mm)에서 두 손가락 안쪽의 최소 유효 폭. 여유는 양쪽 합계6mm(한쪽3mm) 기본.
- 측정 화면의 개방 버튼은 현재팔높이 유지·집게만 해당률로 이동. 팔을 측정높이로 자동이동시키지 않음. 실제높이맞춤/자로측정은 사용자 수행.
- beta_data/gripper_aperture.json 형식: revision,height_mm,margin_mm,gripper_limits,reference,rows[{percent,width_mm}],measured. 동일높이(±0.5mm)·틱범위 확인. 측정된 개방률만 선택, 보간하지 않음.
- make_plan에서 short width+margin <= measured aperture인 최소개방률 선택. 부족하면 물체 접근명령 전 중단. 기존 흐름상 HOME 이동/탑뷰 분석은 그보다 먼저 수행됨.
- 실측없으면 width<60mm만50% 시험예외(미검증 표시). width>=60mm는 측정전 차단. 60mm미만도 실제집기가능 보장은 아님.
- 선택률로개방·반환개방연결. 보정후간격은 측정된 잔여개방폭/여유와 기존px/mm를 참고해 상한을 좁힘. px/mm는 실제 개구부/깊이측정 대체값이 아니며 보이는 반대손가락/주변확인도 유지.
- 고정손가락/카메라등록은공통유지. 움직이는손가락제외영역은 각현재영상의가시윤곽으로재평가, opening_percent/aperture_revision 문맥기록.
- 측정 화면은 연결/실행/완료/실패를1초마다갱신. 아직 입력된 실측값 없음. 임의측정값을 저장하지 않았음.

## 정합/부분 경계
- GapObserver scale=1 초기화. inlier<6 또는scale범위0.8~1.25밖이면 transform=None, 외곽재획득. 회귀검사추가.
- _located_shape는 clipped/clipped_sides를반환. 비율불일치는 감점aspect_ratio_penalty이며 중단안함. live complete_outline 흐름은 항상refine_outline실행.
- 재분리 크기비율도감점. 화면잘림이면 다음을모두필수:
  1) 영상왼쪽 고정손가락쪽 긴경계가충분히보임(40행이상), 세로90도대비15도이내/직선잔차검사.
  2) 예상대상영역과연결(overlap>=25%).
  3) 탑뷰Lab팔레트와느슨한색상일치(거리65내픽셀>=15%).
  4) 탑뷰양쪽손가락여유띠에서초록배경아닌픽셀비율<=18%,표본20개이상.
- 이웃검출목록에의존하지않고실제영상띠를확인. 그림자/반사/흰받침등도비배경으로잡혀보수적중단가능. 새물체/가림전체안전보장은아님.
- visible_boundary 출력은 points,angle_deg,error_deg,clipped_sides,연결근거포함. GapObserver가이경계를추적/재획득하며 gap측정은실제로보이는선구간만사용. 화면밖전체윤곽을상상해간격계산하지않음.

## 조건부 시야 확보
- width>=60mm 큰물건에서만 고정쪽경계가화면8px여유내에안보이거나위치탐색실패할때 실행.
- px/mm*탑뷰폭은예상폭기록용근사,실제경계위치를우선. 반대경계만잘렸으면연결근거/개방폭확인으로부분경계사용.
- 접근높이+20/+35mm(최대100mm)후보에서IK/높이/10도경로검사. 가능한후보만상승. 고정80mm강제안함.
- 높은뷰에서경계를확인해도원래접근높이로복귀해새영상재확인.실제높이이동/정합실패는하강차단.작은물체는의무상승없음.
