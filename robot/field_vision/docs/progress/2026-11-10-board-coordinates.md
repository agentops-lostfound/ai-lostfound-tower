# 보관함 4점 좌표 베타

- 설정 하단 ‘보관함 좌표 · 4점 기준’에서 임시 네 점을 지정한다.
- 순서: 좌상 → 우상 → 우하 → 좌하. 초기값은 현재 화면의 대략적 보관함 위치이며 실측 보정값이 아니다.
- 모드는 임시 4점 / 실제 ArUco. 실제 모드에서는 사전과 각 모서리 ID를 지정하고 마커 중심을 기준으로 변환한다.
- 실제 마커 4개가 같은 분석 프레임에 모두 보여야 한다. 누락 시 임시 모드로 자동 전환하지 않는다.
- 기본 출력: 좌상 원점, 오른쪽 +X, 아래쪽 +Y인 0~1 평면 좌표.
- mm는 기준점 사이 실측 가로·세로를 함께 입력했을 때만 출력한다. 마커 모드에서는 마커 중심 사이 거리다.
- 대상 찾기 결과에 보관함 좌표를 포함하며, 설정 영상 클릭으로 별도 시험할 수 있다.
- 로봇 좌표 변환, 관절 이동, 높이/렌즈왜곡 보정은 구현하지 않았다. 상자 중심의 평면 투영이며 실제 집기점으로 검증되지 않았다.
- API: GET/POST /api/coordinates, POST /api/coordinates/point.
- 검증: 28개 unittest 통과. 합성 ArUco 4개/누락/교차 꼭짓점/정규화·mm 변환 및 실제 서버 설정 저장·좌표 API 확인. 실제 출력 마커 4개 검증은 준비 후 진행한다.
