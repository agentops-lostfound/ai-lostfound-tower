# 중단 작업 점검 및 접촉 후보 조기 정지 재시도

## 보완

- 모터 통신 읽기를 3회 한정 재시도하고 실패 시 위치 유지 정지한다. 무제한 재시도/자동 이동 재개 없음.
- 집게 SRAM 토크 상한 200을 재조회했다. 최초 500 대비 40%이며 힘(N) 측정값은 아니다. 비율 기록이 실제 레지스터 비율을 나타내도록 수정했다.
- load/current/temperature/position/torque limit의 실장비 텔레메트리 조회 추가. 이 장비의 이번 current는 계속 0이어서 접촉 정보로 유효하다고 검증되지 않았다.
- 집게 닫기의 미달 명령을 현재 위치 대비 최대 8 ticks로 제한하고, 접촉 후보에서 현재 위치로 멈춘다. 기존처럼 더 닫힌 목표값을 더하지 않는다.
- 외부 접촉 가드의 motion token을 대조한다. 양쪽 영상 접촉 후보 또는 부하/전류 상승 시 추가 닫기를 멈추는 시험 코드 추가.
- 분홍 튜브/흰 손가락의 규칙 기반 접촉 후보 및 ARM 물체/배경의 상대 움직임 기록 기능 추가. 학습된 AI가 아니며 3D 접촉을 보장하지 않는다.
- 기존 영상은 열린 집게도 겹쳐 보여 이미 접촉 후보로 나왔다. 따라서 초기부터 true인 영상 후보는 새로운 접촉으로 인정하지 않으며 실제 닫기 정지는 부하 상승으로 이루어졌다.
- 잡힘 판정은 held_candidate 또는 unconfirmed로만 반환하고 grasp_success=false를 유지한다. 사용자 육안 확인을 요청했다.
- 원본 시험 보고서를 archives에 복사하여 보존했다. 새 시험은 beta_data/grasp_trials/contact-20261110-170216에 report.json, 단계 사진, ARM AVI 영상으로 저장했다.

## 실제 재시도

- 50% 열기 → 중앙 낮은 위치(임시 모델 Z30mm) → 부하 감시 닫기 → 접촉 후보에서 정지 → 모델 10mm 확인 들기.
- 실제 시작 닫기 raw=2069. 부하 기준값 24에서 48/44로 2회 연속 상승하여 닫기를 중단했다. 목표 최소값 1345까지 닫지 않았다.
- current raw=0, 온도 37도. 접촉력은 측정하지 않았다.
- 영상 판정은 양쪽 겹침 때문에 실제 접촉 근거로 사용되지 않았다. 물체 상대 이동 약 5px, 배경 이동 약 9.5px로 들림 후보가 나왔지만 성공은 확정하지 않는다.
- 사용자 확인 전 재하강/추가 압착/자동 반환/성공 확정 금지.
- 모든 57개 unittest 통과. 토크 상한/텔레메트리 조회/외부 정지/정지 시 추가 압착 없음/영상 중첩 오판 방지/정지 영상의 들림 오판 방지 검증 포함.

## 남은 한계

- 일반 물체의 접촉 분할과 학습된 성공 판별기는 미구현. 현재 분홍색 튜브에 한정된 규칙이다.
- 검출 물품 위치 대신 중앙 고정 좌표를 사용한 시험이다. 임의 위치 자동 집기는 아직 아니다.
- 초기 위치 영점·TCP·5번 회전 부호는 임시 가정이며 목표 Z는 실제 실측 집게 높이가 아니다.
- 팔 어깨/팔꿈치의 도착 잔차 문제가 남아 있다. 기준 허용치를 무작정 넓혀 성공으로 처리하지 않는다.

## 사용자 실물 확인 결과

- 집게는 벌어져 있고 핸드크림은 떨어져 있음. 집기 실패로 확정.
- held_candidate 영상 판정은 기각. 부하 상승 조기 정지는 실제 접촉의 증거가 되지 못했다.
- 추가 동작을 정지했다. 다음에는 물건 없는 집게의 기본 저항/위치·속도 프로파일과 손가락 간격을 확인해 저항 증가를 접촉과 구분해야 한다. 현재 가드는 자동 집기 성공 판정으로 사용하지 않는다.
