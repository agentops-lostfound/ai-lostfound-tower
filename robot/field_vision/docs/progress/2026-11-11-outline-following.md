## 전체 외곽 재분리
- 사진/SIFT/색상으로 대략적 위치를 얻은 뒤, target_color.complete_outline에서 공통 refine_outline 적용. 품목 분기 없음.
- 관측 초록폼 hue를 기반으로 배경 후보를 만들고, 대상 주변 확장ROI에서 비배경을 초기화한다. 저채도 배경과 흰 캡은 hue만으로 분리하기 어려워 공간·색상 경계를 사용하는 GrabCut으로 재분리한다.
- 등록 고정 손가락, 영상 하단에서 진입하는 보조 손가락, ArUco 영역을 제외한다. 대상 위치 핵심영역과 연결된 컴포넌트를 선택하고 내부 인쇄/흰 부분을 포함한 envelope를 만든다.
- 손가락에 가려진 끝부분은 기존 외곽에서 길이방향10% 이내만 유지한다. 기존 잘못된 폭은 복원하지 않는다.
- 길이/폭을 탑뷰 물리 치수와 비율로 비교한다. ARM에서 독립적 깊이(mm/px)를 모르므로 절대 크기를 검증했다고 주장하지 않는다. frame 경계에 닿으면 full_extent_clipped=true; 보이지 않는 전체 길이를 복원했다고 주장하지 않는다.
- 재분리는 GrabCut으로 처리 비용이 증가해 진단 ARM 요청 주기를250→750ms로 조정.

## 측면 추종1회 보정
- 처음 nominal target으로 settled 이동. 정지 피드백과 원래 목표 차이가8틱을 넘는 팔 관절에 nominal+(nominal-feedback)로 한 번 보냄. 오차가40틱을 넘으면 보정 안 하고 중단. 관절 범위, 경로높이/방향 검사 유지.
- wrist_roll은 held_goal을 유지하는 앞선 합의 때문에 자동 가산하지 않음. 손목 오차8틱 초과는 방향 재확인 오류. gripper/닫기/추가닫기에 적용하지 않음.
- 보정 명령은 원래 목표와 별도로 기록하며 held_goal에는 원래 목표를 유지한다. 원래 목표 오차가 개선되지 않으면 중단.
- 보정 원리상 raw command FK는 정상 목표를 넘지만 실제 정상상태 편차를 상쇄하려는 명령이다. 측정편차 유지 가정의 응답 경로와 raw 명령 경로를 구분 검사한다. raw 높이편차12mm 한도, 예상 응답은 현재 오차부터 회복 가능한 범위, 기준평면+20/10도 한도를 검사한다. 실제 응답은 반드시 사후 FK로 높이4mm/옆3mm 및50% 이동 조건 확인.
- 기존 같은목표 재시도는 이 경로에서 사용하지 않고 nominal+보정 최대2회 명령만 보냄.
- 마지막 접근과 하강은 이번 자료에서 큰 반복오차가 입증되지 않아 자동보정을 확대하지 않음. 접근1/2의 +27틱은 관측했지만 물체 위 마지막 접근/하강과 동일하지 않음.
