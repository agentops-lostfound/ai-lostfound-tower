# 보관함 → 측정 로봇 기준 목표 미리보기

- 실측한 좌상 0, 우상 1, 좌하 3 마커 중심의 로봇 기준 X/Y/Z(mm) 3점을 저장한다.
- 같은 원점과 축을 사용해야 한다. 측정 원점 예: 맨 아래 회전축의 바닥 투영점. +X는 현장에서 정해 표시한 방향, +Y는 그 왼쪽, +Z는 위. 실제 URDF 베이스 축과의 정합은 별도 검증 필요.
- 보관함 가로 468.8mm, 세로 202mm와 기준점 거리, 직각, 수평 배치를 검사한다. 실제 움직임에 대한 정확도 보장은 아니다.
- 보관함 설정 변경 시 이전 변환 사용을 거부한다.
- 목표 표면 위치와 마커 평면 위 20~200mm 접근 위치를 계산한다. 기본 80mm는 계산용 값이고 물체 높이·받침·경로 검토가 필요하다.
- 기능은 설정 하단에 있으며, 새 검색 결과에서 대상 mm 좌표를 불러올 수 있다.
- API: GET/POST /api/robot/frame, POST /api/robot/preview.
- 3점 측정은 FK/IK, 관절각 정합, 집게 TCP 보정을 대신하지 않는다. normalized를 각도로 해석하지 않는다.
- 이번 단계에서 가상의 실측값을 실제 설정에 저장하지 않았다. 로봇 이동 명령 없음.
- 33개 unittest 통과. 실제 로봇 기준점 입력·이동 검증은 미완료.
