# 고정 손가락 겹침 / 접근 오프셋 통합 수정 — 2026-11-11

버전: BETA 0.2.2 / 20261111.02. 로봇 이동 없이 오프라인 검증 후 유휴 서버에 적용.

## 바뀐 동작
- `GapObserver`가 개방 직전 물체 box를 저장한다. 개방 후에는 고정 손가락 영역을 제외한 물체 특징을 LK 전후방 추적 + RANSAC으로 정합한다. 8px 이상 이동/5% 이상 크기 변화는 재측정으로 기록하고 매번 최신 영상으로 특징을 갱신한다.
- 추적 근거가 부족하면 대상 참조와 다시 매칭한다. 무늬가 없는 물건은 외곽 크기가 85~118% 안에 유지되는 경우만 재획득한다. 가림으로 줄어든 단편을 전체 외형으로 승인하지 않는다.
- 가림으로 손가락이 제외된 contour 대신 완성된 box를 사용한다. 손가락이 영상 하단에서 들어오는 현재 등록 구조의 끝부분(상단45%, 최소24행)에서 행별 간격의 하위20%를 판정한다.
- 보정과 하강 전 fixed 판정은 같은 observer/함수/허용범위를 쓴다. 하강 전 fixed 실패는 재보정으로 돌아가며 동일한 세션의 12mm/4회 한도를 유지한다. 여전히 실패하면 예외로 하강 차단. fixed 통과 + 보조 손가락만 실패한 경우만 경고 허용.
- 영상 보정 시작 명령 위치를 고정 원점으로 사용한다. 명령량을 누적해 ±12mm 범위를 검사하고 실제 피드백 이동량은 px/mm 추정에만 사용한다. 실패 시에도 2개 이상 같은 부호/크기비2.5 이내의 반응이 있으면 저장한다.
- 작은 측면 이동은 변경 관절마다 허용 오차 min(24,max(2,변화량/2))를 사용한다. 일정한 중력 처짐을 허용하기 위해 최초 피드백 대비 실제 관절 변화량을 검사하며, 절대 목표 오차46틱도 함께 제한한다. 목표변화12틱일 때 이동0/5틱은 미도착, 12틱은 도착인 검사 통과. 워커는 기존처럼 전체 보간시간 이후에만 완료를 판단한다.
- 명령상 ±12mm 제한과 실제 도착 위치는 다른 값이다. IK 양자화 및 피드백 오차가 있으므로 물리적인 정확한 ±12mm 상한 보장은 아님.

## 품목 공통 접근 오프셋
- 탑뷰 짧은축 양 끝을 보관함/로봇 평면으로 변환한 폭을 plan.short_axis_width_mm에 저장한다.
- k=0.5, c=4mm, 사전 오프셋 상한30mm. 양의 벌림축 이동으로 영상 간격이 증가한다면 +방향으로 적용한다. 기존 목표에서 계산된 signed opening_axis를 고정해, 오프셋 경로가 반대180도 손목 분기로 바뀌지 않게 한다.
- 검증된 slope가 없으면 사전 오프셋0. 임의의 부호를 주입하지 않는다. 처음 겹침이 커서 12mm로 해결하지 못할 수 있으며, 일관된 반응이 저장되면 다음 시도부터 사전 오프셋이 적용된다.
- 학습 키: working_calibration/orientation_alignment/고정손가락/카메라설정/TCP 파일 해시, SIGN, URDF, 실제 관절범위, ARM 소스/해상도. 이전 형식의 해시 없는 slope는 재사용하지 않는다.
- 종료 시 폭·사전 오프셋·영상 보정 명령량·합계를 기록한다. 최종 간격을 통과한 관측만 학습한다. 품목별 키 없음. 최소4개 관측 + 폭 분산10mm 이상일 때만 k/c를 강건하게 재추정한다. 동일 폭 반복으로 두 계수를 억지로 추정하지 않는다.
- k/c/사전 상한은 운영·집기 설정에 추가. 학습 계수가 존재하면 초기 k/c 대신 학습 계수를 사용한다.
