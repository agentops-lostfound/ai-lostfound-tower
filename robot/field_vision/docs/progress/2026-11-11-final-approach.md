## 요청과 수정
- flow-3196daf5 마지막 접근에서 팔꿈치 +34틱으로 정지, 기존24틱 도착 기준 시간초과. 기록FK는 목표대비 XY6.86mm/Z-9.51mm.
- 마지막 접근과 하강에 checked_stage_move: settled 이동 → 원래목표 대비8틱 초과 오차를 nominal+error로1회 보정(40틱 상한) → settled → 피드백 FK 확인. 보정 목표는 held/계획 원래 목표에 누적하지 않음. 손목 고정/그리퍼 제외 정책 유지.
- 보정 명령은 현재 피드백의 정상상태 편차를 가정한 응답 경로와 raw command 경로를 각각 검사. 관절범위,10도방향,높이하한 유지.
- 접근 확인은 원래 명령FK 기준 XY<=3mm, 높이 ±4mm.
- 하강은 물체 근처이므로 XY<=3mm, 높이 +4/-1mm, 절대하한 plane_z+3mm. 현재 피드백이 하강 하한 아래면 추가보정을 보내지 않음. 물체 높이/접촉을 측정하는 기능은 아니며 이 기준만으로 물체 무접촉을 보장하지 않음.
- 완료된 정지 상태의 보정·FK 검증 실패는 MotionAborted로 일반중단(phase=aborted), 추가 STOP/정지잠금 요청 안 함. 통신오류,워커추종오류,실행중오류는 기존 STOP/연결오류 경로 유지. 이미 하드웨어 잠금이 걸렸으면 해제하지 않음.
- 목표Z<=100mm에서 팔관절 변화15도 초과는5초. 기존45도 초과5초도 유지. 마지막접근/중간점/하강/측면에 목표높이를 전달.
- path_cost는 총관절이동량+3*마지막구간최대변화. 평행축 중간점 후보를 점수순으로 검사하며 targetXY 위+12/+20mm 수직접근 후보도2개만 추가. 모든 선택 경로는 기존safe통과. 전체IK대안탐색은 다시 무제한 확장하지 않음.
