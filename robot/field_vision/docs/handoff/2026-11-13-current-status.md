## 실제 운영 설정

| 항목 | 최신 로컬 전달값 |
|---|---|
| 접근 / 기본 집기 높이 | 45mm / 5mm |
| 설정 간격 | 6~56px, 실행별 재계산 |
| 보정한도 / 추가닫기 | 20mm / 2초 |
| 종료 / 놓기 자세 | return / 저장됨 |
| 이송 높이 | 120mm |
| return_on_unconfirmed | **false**, 미확정 파지는 반환하지 않음 |
| auto_intake | false |

이 값은 원본 로컬 설정이다. 저장소의 제외된 운영 DB·보정·설정 파일을 배포했다는 뜻은 아니다. v1.0.8의 작은 물품 +2mm 계산과 기본집기5mm도 구분한다. '1틱≈0.4mm'는 특정 자세 근사로 모든 관절·작업공간에 쓰지 않는다.

## 실물 근거와 성공 판정

사용자는 최근 실제 집기가 잘 된다고 확인했다. 과거 실패만으로 현재 집기를 실패·전부 미검증으로 되돌리지 않는다.

| 품목 | 확보한 근거 | 표현할 때 구분 |
|---|---|---|
| USB | 최근 flow-433788d4(axxen), flow-2c5ecd50(sandisk_black): held_likely, returned=true, 놓기 완료·HOME 복귀, error 없음 | physical_success_verified=false이며 최상위 success/grasp_success도false. 실물 성공 확정과 자동 로그를 구분 |
| 보조배터리 | flow-d2a745b6(Powerbank_black): 같은 완료 로그, 영상 미확정을 집게 막힘으로 보완 | 과거 '완료 기록 없음'은 오래된 정보. 실제 파지 성공 확정으로 승격하지 않음 |
| 립밤 | 빨간 립밤 flow-062c7b24(v0.2.104): 약306mm 먼 칸 접근→집기→반환→HOME 자동완료 기록 | 최신 알고리즘 변경 후 회귀는 별도 확인 |
| 핸드크림 | 발표 누적 자료상 반환완료3회 | 최신 조임·말랑한 물체 파지 보완의 검증 범위는 별도 |
| 휴대폰 | v0.2.99 실물 파지 사용자 확인 | 반환/HOME은 구간별 실행이므로 무조건 완전자동 한 바퀴 성공이라고 하지 않음 |
| 지갑 | 이번 점검에서 성공 근거 미확보 | 물리적으로 집을 수 없다는 결론은 아님 |

최근 세 건의 **완료 로그·물리 확인 필드·최상위 성공 필드가 일치하지 않는다.** 필드 의미와 갱신 경로를 정리하기 전에는 한 필드만 골라 성공률을 만들지 않는다. 원본 실행 로그와 사진은 게시하지 않고 사례 ID와 관찰만 전달한다.
