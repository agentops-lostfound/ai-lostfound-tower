# 실제 관절 방향 확인

- 장비: SO101 Follower 팔로워 일련번호.
- 1번 shoulder_pan: GUI ＋(엔코더 ticks 증가)를 누르면 로봇이 보관함을 바라보는 기준으로 오른쪽 회전. 사용자 관측.
- 모델의 영점·각도 스케일·좌표축 정합은 아직 검증되지 않음. 이 방향 확인만으로 자동 좌표 이동을 허용하지 않음.

- 2번 shoulder_lift: GUI ＋ 시 보관함 쪽 전방으로 들리며 나가는 움직임. 사용자 표현을 보존하며 순수 상하 방향/URDF 부호는 미확정.

- 3번 elbow_flex: GUI − 시 보관함 반대쪽으로 들리는 움직임. 사용자 표현을 보존하며 펴짐/접힘·URDF 부호는 미확정.

- 4번 wrist_flex: 현재 자세에서 GUI ＋ 시 집게가 보관함 쪽으로 넘어가는 방향. 순수 상하·URDF 부호는 미확정.

- 5번 wrist_roll: GUI ＋ 시 손목에서 집게 끝을 바라보는 기준으로 시계방향 회전. 사용자 관측이며 URDF 방향 정합은 미검증.

- 6번 gripper: GUI ＋ 시 집게 벌어짐. 실제 열림 폭과 모델 각도 정합은 미검증.

방향 설명 6개 수집 완료. 특히 2·3·4번은 자세에 의존하는 자연어 관측이며 모델 영점/부호 검증 완료를 뜻하지 않는다. 다음은 위치와 자세를 아는 기준 자세에서 관절 피드백과 카메라를 함께 저장하여 기구학 정합에 활용하는 단계.
